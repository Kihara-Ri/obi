# 更多转场：封面入抽屉、列表重排、Details 动画、展示模式

- 详情抽屉：封面从库存卡片 / 行飞进抽屉大图，关闭时飞回（`core/cover-fly.ts`，克隆图 + 抽屉动画终点量位置；来源不在屏幕上则不飞）。Drawer 关闭时派发 `drawer-closing`。
- 库存重排：搜索、排序、筛选、新增、移除后，卡片 FLIP 移动，新卡片淡入放大（`pages/useListFlip.ts`）。被移除的卡片无法淡出，由后面的上移填补。
- `Details` 组件替代 7 处裸 `<details>`（售出更多信息、上架记录、发行资料、包装、艺人资料等）和 `Disclosure`：高度 + 淡入，箭头统一 Chevron。
- 展示模式切换：场景按 mode 重挂载并淡入缩放；空状态淡入。
- 已有、未改：底部批量条、Toast、底栏滑块、展示聚焦（原本就有进出场动画）。
- 未验证：真机；封面飞行与抽屉滑入的同步观感；Details 在抽屉内高度变化时的滚动表现。
