## 改了什么
按 `.tmp/黑胶支持方案.md` 做完第 2–4 步（D-055）：
- 黑胶副本的包装只列单封套 / 对开封套 / 套装盒三种预设，配正面画法的图标；只存英文术语，不生成 3D。
- 新增可选字段 `vinyl`：尺寸、转速、彩胶、唱片 / 封套品相（Goldmine）。表单在包装下方填写，详情页显示「规格」「品相」两行。
- 列表标签写「12″ 黑胶」；库存里有黑胶时工具栏出现「全部介质 / CD / 黑胶」筛选。
- 采购评估：填了黑胶规格的副本按 LP 统计。
- 上架资料包带 `copy.medium` 和 `copy.vinyl`，闲鱼文案和运费交给外部 Agent。
- 黑胶样本加一张国内库存的 Meddle 12″ LP（原来三张黑胶全在在途或已售，库存里看不到），四张都写上包装、规格和品相。

第 5 步（黑胶 3D）以后在引擎项目做。

## 出现的问题
- 源码正则测试 `copy-edition.test.mjs` 写死了 `version: releaseInfo.packaging`，改成走 `initialPackaging` 后失败。
- 窄屏下工具栏多一个介质下拉后放不下，「卡片」字被截断。
- 筛到黑胶后没有结果时提示「库存是空的」，不对。
- 构建后浏览器还在用旧的 ShelfPage 分块。
- 第 3 个品相按钮点击后截图仍显示旧值：分段滑块动画还没走完，实际已选中。

## 怎么解决的
- 测试正则跟着改。
- 有介质下拉时，窄屏视图切换只留图标。
- 筛空时单独提示「这里没有黑胶」，并给「看全部介质」按钮。
- 构建后刷新页面。
- 黑胶副本里残留的 CD 包装预设当作未确认，表单要求重选黑胶预设。
