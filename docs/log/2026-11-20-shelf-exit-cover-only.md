# 2026-11-20 · 库存离开动画：只飞封面

- **作者**：Claude
- **范围**：`web/src/pages/useListFlip.ts`

## 改了什么
- 专辑因状态变化离开列表、导航里有去处入口时（售出 → 「售出中」、调回海外 → 「海外库存」等），原来是整张卡片的替身浮起再飞走。现在只把**封面**单独抽出来飞：
  - 封面带圆角，浮起一点、加阴影，再缩小飞向导航入口，入口轻跳一下。
  - 圆角取封面或其外层的圆角；卡片视图的封面本身是直角，退回全局 `--radius`。缩小过程中按比例放大圆角，落到入口时仍看得出是圆角。
  - 卡片其余部分原地淡出，封面原位置留空，像封面被拿走了。
- 没有可见入口（移入回收站、被筛选掉等）仍是整张卡片原地缩小淡出，不变。
- 上一帧额外记下封面相对卡片的位置与圆角：卡片被摘掉后就量不到了。

## 出现的问题
- 用户反馈整张卡片一起飞太重，希望只移动带圆角的封面。

## 怎么验证的
- 示例预览桌面 1280：国内库存全选「调回海外」，冻结动画在 330ms / 500ms 截图：两张圆角封面离开卡片，卡片其余部分已淡出，封面朝侧栏「海外库存」飞去。测试前备份示例数据，测完已恢复。
- 前端单测、类型检查、构建、后端测试、文档检查、浏览器验收通过。

## 可能带来的新问题
- 没有封面的专辑（首字占位块）飞的是占位块，样式依赖页面作用域的外壳 class。
