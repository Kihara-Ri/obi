# 2026-11-04 · 修复已绑定发行版的专辑无法改买入信息

- **作者**：Claude
- **范围**：`server/routes.py`（`api_records`）、`tests/test_barcode_edits.py`、`CHANGELOG.md`

## 改了什么
`api_records` 的发行版核对在请求没带 `releaseInfo` 时直接跳过，保存沿用旧资料。

## 出现的问题
编辑买入信息（金额 / 日期 / 费用 / 渠道）的请求不带 `releaseInfo`，服务端把缺失当成「条码与发行版被清空」，对已绑定发行版的专辑报「条码或发行版本已修改，请重新查询并确认发行版」，导致无法保存。

## 怎么解决的
有 `releaseInfo` 才核对（显式清除条码仍被拦）。放弃的方案：让前端把旧 `releaseInfo` 原样回传——多余，且别的只改部分字段的入口仍会踩坑。新增回归测试：只带价格保存，发行版与条码保留。

## 可能带来的新问题
无已知隐患，已验证：后端 585 项、前端测试、typecheck、build 通过；已部署 rasp5remote，健康检查通过。未在真机上实际保存验证。
