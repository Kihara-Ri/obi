- **作者**：Codex
- **范围**：架构复盘后的 I-018 / I-019 / I-020 实施，决策 D-040 至 D-042。

## 改了什么

- 完整 ZIP 恢复先校验并保留同盘暂存，账本与恢复日志在同一事务提交；目录切换可重复执行。启动和后续 API 请求补完中断的恢复；导入不信任外来恢复日志。旧文件保存在 pre-restore。
- 本机 Worker 不再忽略 FS.syncfs 错误。写请求串行，成功落盘才确认；客户端在发请求前记录操作标识。Worker 回执重试只补写磁盘，不重执行业务。未知回执拒绝执行，未落盘时阻止其他写入。回执保留有上限，使用请求摘要，不保留大上传请求体。
- 发布从 detached Git 快照工作树安装依赖、构建、测试和打包；个人配置只读引用，不复制 data。远程 fetch 失败即停止。源码提交、包哈希与 ship 退出码关联保存；退出后清理临时工作树。
- `.tmp/` 加入忽略，分析和验证产物不进入后续部署源码快照。
