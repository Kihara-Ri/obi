# 2026-11-25 · Obi v3.16.0 发布准备

## 改了什么

把黑胶录入、扫码和编号识别介质、服务器 MCP 接口及在途和售出中专辑行的显示更新归入 v3.16.0。

## 出了什么问题

发布前确认线上构建与远端主分支对应同一份应用代码。这次提交只更新发版记录。

## 怎么解决

按 D-024 先推送更新记录，等待目标提交的 CI 通过后打标签。正式发布附服务器包及 SHA-256，安卓附件由签名工作流上传。

## 可能带来的新问题

v3.16.0 升了次版本。已有安卓用户从 3.15 升级时需要确认安装新 APK，服务器也需要部署新版本才能使用该正式版号。
