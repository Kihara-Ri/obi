# 2026-11-17 · 手机库存列表行：左滑操作与紧凑排版

## 问题与处理

用户反馈手机库存列表信息显示不全（艺人、元信息被截成「…」），标题 / 艺人 / 元信息上下空隙大、左右没用好。原因：行高锁死在封面高度、三行文字分别贴顶 / 居中 / 贴底；右列金额加 88px 宽的「记录售出」按钮占掉约四分之一行宽；「已上架」徽标挤在元信息同一行。先出了现状 / 方案 A（缩小按钮）/ 方案 B（去掉行内按钮、左滑操作）三张设计稿（`.tmp/shelf-mock/`），用户选 B，并要求包装形式保留图标、信息短时上下匀称。

实现：新增通用件 `components/ui/SwipeRow`（只接管触摸，横向拖过一半停在展开位，同时只展开一行，点行外 / 内容层收回，展开时内容层点按不触发，选择模式停用；收起时不裁切，不影响列表↔卡片的 FLIP 动画），已登记 `REGISTRY.md`。`Cards.tsx` 列表行外层改为 `SwipeRow`，`ShelfPage` 传入「上架 / 下架」（bulk `list` / `unlist`）与「记录售出」；手机上有左滑操作的行收起行内按钮。`Cards.css` 手机网格改为上下两条 `minmax(0,1fr)` 空行夹住标题 / 艺人 / 元信息，元信息跨到金额下方并按项折行，已上架改成封面右上角绿勾。`界面与功能定案.md` 已补条目。

## 验证与风险

类型检查、构建、前端测试通过。样本手机视口（390 / 340，深浅两色）：每行 96px（封面 76 + 上下 10），文字块与封面居中，包装图标正常，无横向溢出；CDP 触摸模拟验证点行进详情、左滑后点「记录售出」打开售出抽屉、点行外收回、选择模式下左滑无效，控制台无错误。真机 iOS 上 `touch-action: pan-y` 与系统手势的配合、左滑的手感（阈值一半、阻尼）需要用户实机试一下；左滑没有界面提示，第一次需要知道这个手势。

## 追加：首次演示左滑

用户选择「首次进入时演示一次」。`SwipeRow` 新增 `hint` / `onHintShown`：延迟 900ms（等页面切换动画结束）用 Web Animations 把内容层滑开 60% 停一停再收回，手指一碰就取消；只在手机宽度、未要求减少动画时播放。`pages/useSwipeHint.ts` 用 localStorage `obi-swipe-hint` 记住已演示，`ShelfPage` 把它交给当前列表第一行可左滑的专辑（选择模式、卡片视图不演示）。样本手机视口：首次进入第一行滑开到 -91px 露出操作、播完收回并写入标记，刷新后不再播放，控制台无错误。
