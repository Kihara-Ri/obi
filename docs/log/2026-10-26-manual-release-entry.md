# 2026-10-26 · 添加专辑：手动录入入口常驻

- **作者**：Claude
- **范围**：`forms/record/ReleaseLookupSection.tsx`、`ReleaseLookupSection.css`、`useReleaseLookup.ts`（提示文案）、`CHANGELOG.md`

## 出现的问题
用户反馈：找不到发行信息的专辑无法入库。手动录入（D-014）其实存在，但只在查询返回「查不到」后才出现；没有条码 / 编号的专辑不会进入该状态，没有任何入口，保存只报「请先确认发行版本」。

## 怎么解决的
- 新增专辑且尚未填名称、未确认、未手动时，发行版输入框下方常驻「没有条码或编号？按未收录版本手动录入」。
- 「查不到」状态里的小号 quiet 按钮改成正常样式的「按未收录版本录入」。
- 手动录入后的提示改为一行，说明之后可在「待确认发行版」补查。
- 保存口径不变：仍标记未经核对、不生成 3D；编辑旧记录时不显示该入口（避免误改为「已处理」）。

## 验证
前端 typecheck / build 通过；样本库 375×812 打开添加专辑，入口可见，点击后进入手动录入、出现专辑名 / 艺人输入，控制台无报错。
