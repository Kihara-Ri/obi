# 2026-10-23 · 扫码层底色改为不透明（修「方框闪一下」的根因）

- **作者**：Claude
- **范围**：`web/src/components/BarcodeScanner/BarcodeScanner.css`、`CHANGELOG.md`

## 改了什么
`.scan-layer` 的背景由 `var(--shadow-ink)` 改为 `black`（不透明）。

## 出现的问题
用户反馈：打开扫码仍有一个方框闪一两帧。此前我按「相机启动期尺寸跳变」的假设做了稳定等待和快门式过渡，没有消除。

## 怎么解决的
从渲染原理重新分析：扫码层背景是 `--shadow-ink`（浅色主题 rgba(23,32,58,.18)，几乎透明），取景框用 `box-shadow:0 0 0 100vmax` 给框外再叠一层暗角。框内只有一层 18% 的暗，框外有两层，所以相机出画前，框内透出背后页面，成了一个比周围亮的「小窗」；画面一出来又铺满全屏，就是用户看到的「小方窗 → 扩展到全屏」。这与相机、视频尺寸无关。改成不透明黑底后，出画前框内框外同黑。用 CDP screencast 逐帧采样验证：页面淡到黑的过程中框内外亮度一致，没有窗口，随后相机淡入。放弃继续调视频显现时机：方向错了。

## 可能带来的新问题
进入扫码时背后的页面不再隐约可见（从半透明变为淡入到纯黑）；若真机上仍闪，说明还有视频原生层的问题，下一步改为把视频帧画到 canvas 再显示。未在真机验证。
