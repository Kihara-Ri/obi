# 2026-11-19 · 手机多选：操作条替换底栏，不再挡住专辑

- **作者**：Claude
- **范围**：`web/src/pages/BulkBar.tsx`、`web/src/pages/BulkBar.css`、`web/src/pages/ShelfPage.tsx`

## 改了什么
- 手机上进入选择后，按 iOS 多选惯例分成两处：
  - 顶栏换成「取消｜已选 N 张｜全选」。
  - 底部导航换成一行操作条，同高 58、同位置。
- 操作超过 3 个时，只露出前 2 个，其余收进「更多」，从操作条上方弹出菜单。例如国内库存显示「合单售出 / 标记上架 / 更多」。
- 上架/下架按选中专辑的状态给：全未上架只给「标记上架」，全已上架只给「取消上架」；混选时给「上架 N 张」（操作条）与「下架 N 张」（更多）。只对会变的那几张发请求，提示写明张数。
- 没选中时，操作按钮置灰，顶栏显示「选择专辑」。
- 工具栏里的「全选」和「取消选择」在选择期间隐藏，已挪到顶栏。
- 桌面端不变，仍是一行浮条、全部操作平铺。

## 出现的问题
- 原来的手机批量条是三层（数量行、主按钮、2×2 网格），约 290px 高，又叠在底栏上方，两者共占将近半屏。
- 页面底部只给底栏留了 120px，多出的浮条没有对应留白，最后几张专辑滚不出来，选中的也会被压住。

## 怎么验证的
- Playwright 手机 390×844 深色，用固定样本跑以下流程：
  - 进入选择：顶栏和操作条显示正确，0 张时按钮置灰。
  - 选 2 张，打开「更多」：菜单在操作条上方弹出。
  - 滚到底：最后一张的下沿 718px，在操作条上沿 778px 之上，不被遮挡；选择期间底部导航隐藏。
  - 取消：底部导航恢复，操作条卸载。
- 上架状态：只选已上架的 → 「合单售出｜取消上架｜更多」；混选 → 「合单售出｜上架 1 张｜更多（下架 1 张…）」；只选未上架的 → 「标记上架」。
- 桌面 1280 宽：浮条与原来一致。

## 可能带来的新问题
- 选择期间不能直接切换页面，要先取消，和 iOS 相册一致。
- 「移入回收站」进了「更多」，需要多点一下；它本来就可以从设置里恢复。
