# 2026-10-20 · 编辑表单紧凑化、封面 bug、封面区重做、购买信息与购买渠道分组

- **作者**：Claude
- **范围**：`forms/record/pickRelease.ts`、`CoverPanel.tsx`、`MoneySection.tsx`、`forms/RecordForm.tsx`、`components/ShopField.tsx`、`core/shop-groups.ts`（新）、`web/tests/shop-groups.test.mjs`（新）、`styles/drawer.css`、`ShopField.css`

## 改了什么
- **封面 bug（旧记录原有好封面被首字母顶替）**：选定发行版时，`pickRelease` 会先把 `base.cover` 清空并置「无封面」，再异步匹配；匹配不到（或还没回来就保存）封面就留空，界面显示首字母占位。现在已有封面一律保留，只在没有封面时自动匹配，且只有找到新封面才写入；想换封面点「重新匹配」。
- **封面区重做**：当前封面缩略图 + 「封面」+ 正文字号的一句状态（使用现有封面 / 保留现有封面 / 查找中（转圈）/ 已匹配 · 来源 / 尚无封面…）+ 「重新匹配」；候选缩略图在下方。
- **购买信息**：改成与「记录售出」同款的行式分组（买入金额 + 币种分段在右、买入日期、额外费用、折合成本说明行、购买渠道、入库位置），去掉卡片套卡片。
- **购买渠道分组**：
  - 品牌匹配先压缩店名（去空格 / 连字符 / 点 / 中点），「Book Off」「BOOKOFF」「ブックオフ」同属一家，松本店不再单列；
  - 已知连锁用规范品牌名做一级标签（BOOKOFF、Disk Union、Tower Records…），不再拿某一家分店名当一级；
  - 未知品牌按公共前缀成组（英文数字 ≥4 字符、其他文字 ≥3 字符）；
  - 分组逻辑抽到 `core/shop-groups.ts`（纯函数）并补 5 个单测。
- **整体紧凑**：编辑 / 添加表单输入框、下拉、字段间距缩小一档，textarea 最小高 56px，分区标题上方加分隔线（专辑资料 · 购买信息 · 备注），标签与分店标签更矮。

## 出现的问题
- 「封面匹配功能被弃用」：自动匹配原来靠专辑名 / 艺人输入框的失焦触发，现在这两栏只在更正时才用；自动匹配改为只在选定发行版且无封面时触发，其余靠「重新匹配」（仍用专辑名 + 艺人搜索）。
- 分组首版（上一轮）把「首词」当品牌，分店名会出现在一级；已改。

## 怎么解决的
前端 125 项测试（含新增分组测试）、类型检查、构建通过。iPhone 17 Pro 模拟器：编辑表单的紧凑布局、封面区、购买信息行式分组；对旧记录输入条码并选版本后封面保留、状态为「保留现有封面」。

## 可能带来的新问题
- 品牌别名表仍来自内置图标表（亚马逊、乐天、Mercari、BOOKOFF、Disk Union、骏河屋、Tower、Meditations、Recofan、丸善等），不在表里的连锁只能靠前缀成组；真实店名与规则不符的需要补别名。
- 选定发行版时不再自动换封面：若新版本封面与旧封面不同，需要手动点「重新匹配」。
- 紧凑化使用 `#record-form` 作用域，只影响添加 / 编辑专辑表单，其他抽屉未动。
