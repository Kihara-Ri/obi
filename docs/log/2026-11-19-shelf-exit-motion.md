# 2026-11-19 · 库存：专辑离开列表时有去向动画

- **作者**：Claude
- **范围**：`web/src/pages/useListFlip.ts`、`web/src/pages/ShelfPage.tsx`

## 改了什么
- 专辑因操作离开当前列表（售出、调回海外、移入回收站、批量操作、被筛选掉）时，原位置先留一个替身，再走一段动画，而不是直接消失：
  - 有去处且导航里看得见入口（手机底栏 / 桌面侧栏）：替身先轻微浮起，再缩小飞向入口，入口随后轻跳一下。例如售出 → 「售出中」，确认收货后 → 「交易记录」。
  - 没有可见入口（移入回收站、选择模式下底栏已隐藏、去处就是当前页）：原地缩小淡出。
- 后面的卡片等替身离开约 140ms 再上移补位；抽屉还在收起时，整体再晚 200ms 开始，让替身先露出来。
- 一次最多 12 个替身，依次错开 40ms；只处理在屏幕内的。减少动态效果时不播。

## 出现的问题
- 原来的重排动画只能移动留下的卡片：被移除的卡片 React 已摘掉节点，直接消失，只剩一条提示，看不出专辑去了哪里。

## 怎么验证的
- Playwright 桌面 1280：在国内库存记录售出，暂停动画逐帧截图，替身从原位浮起并飞向侧栏「售出中」，结束后替身层移除。
- 手机 390：卡片视图记录售出，替身在抽屉之下、底栏之上，飞向底栏「售出中」；选择模式下批量移入回收站，原地淡出，后面行随后上移，替身层清理干净。
- 前端测试、类型检查、文档检查与售卖浏览器验收通过。

## 可能带来的新问题
- 替身是卡片的静态副本，挂在 body 上、外面套与页面同名 class 的壳保留样式；若以后卡片样式依赖更深层的祖先，替身可能少些样式。
