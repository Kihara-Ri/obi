# 2026-10-21 · 封面候选排版

- **作者**：Claude
- **范围**：`web/src/styles/drawer.css`（`.cover-candidates` / `.cover-choice`）、`forms/record/useCoverSearch.ts`

## 现象
发行版卡片里的封面候选是横向滚动的 96px 小缩略图，靠左，右边大片空白；标题/艺人 10px 且被省略号截断；状态只写「点击选择封面」，看不出这是个按钮。

## 改动
- 候选改成网格（每列至少 132px，手机两列），封面更大。
- 标题 13px、艺人·年份·来源 11.5px，最多两行，不再截断。
- 每张底部加「使用这张」按钮样式条；状态文案改为「找到 N 张封面，点选一张使用」。

## 验证
typecheck、web 测试、构建通过；未在真机截图确认。

## 追加：换排版（网格 → 横条 + 叠放）
网格仍是「封面在上、文字在下」，高且横向利用差。改为：
- 候选每张是一整行：左 56px 封面，中间标题 / 艺人·年份·来源，右侧「使用」；一行就占满宽度。
- 多张时先折叠成一条「叠放封面」（最多 5 张重叠）+「N 张候选，点开选择」，点开才出列表（最高 46vh 内滚动）；只有一张时直接显示那一行。
- 已确认卡片头部封面 64→76px。
- 未在真机截图确认。

## 追加：「使用」按钮遮住文字
候选行是 `<button>`，按钮继承了 `white-space:nowrap`，说明文字不换行、被右侧「使用」压住（grid 单列也是 auto 宽）。行上显式 `white-space:normal`，文字列改 `minmax(0,1fr)`；服务商行同样处理。未在真机确认。
