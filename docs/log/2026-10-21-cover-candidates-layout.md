# 2026-10-21 · 封面候选排版

- **作者**：Claude
- **范围**：`web/src/styles/drawer.css`（`.cover-candidates` / `.cover-choice`）、`forms/record/useCoverSearch.ts`

## 现象
发行版卡片里的封面候选是横向滚动的 96px 小缩略图，靠左，右边大片空白；标题/艺人 10px 且被省略号截断；状态只写「点击选择封面」，看不出这是个按钮。

## 改动
- 候选改成网格（每列至少 132px，手机两列），封面更大。
- 标题 13px、艺人·年份·来源 11.5px，最多两行，不再截断。
- 每张底部加「使用这张」按钮样式条；状态文案改为「找到 N 张封面，点选一张使用」。

## 验证
typecheck、web 测试、构建通过；未在真机截图确认。
