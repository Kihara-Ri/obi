# 2026-10-23 · 安卓沉浸：模拟器实测 + 系统拒绝时给提示

- **作者**：Claude
- **范围**：`android/.../MainActivity.java`、`CHANGELOG.md`

## 实测
用本机 Android 模拟器（API 35，原生系统）装 debug 包：点「沉浸展示」后状态栏 / 导航栏 `InsetsSource visible=false`，横屏同样隐藏，从屏幕边缘下滑能临时唤出状态栏——壳的逻辑在原生系统上是对的。用户手机（带运营商名 / 眼睛图标的厂商 ROM）仍显示状态栏，说明是该 ROM 不理会隐藏请求或另有设置。

## 改了什么
1. 沉浸时加 `FLAG_LAYOUT_NO_LIMITS`（退出时清除），让窗口铺出屏幕边界。
2. 进入沉浸 2.2 秒后若状态栏仍可见，弹一次 Toast：「系统拒绝隐藏状态栏（厂商 机型 / Android 版本）」，用来拿到具体机型。

## 可能带来的新问题
- 不保证修好用户那台手机；Toast 只在系统拒绝时出现一次（每次启动）。
- 可能需要用户在系统设置里给应用打开「全屏显示 / 沉浸」之类的厂商开关。
