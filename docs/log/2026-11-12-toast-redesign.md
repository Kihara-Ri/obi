# 2026-11-12 · 消息提示重新设计

## 问题与处理

用户反馈 toast 的“彩线沿圆角矩形边框环绕”与整体界面不搭。改为与底部导航、沉浸悬浮条同一浮层语言：`--chrome-nav` 毛玻璃底 + 细边 + 阴影的胶囊（单行为全圆角，换行时保持 22px 圆角），左侧实心圆点内放 ✓ / ! / × 区分级别（状态不只靠颜色，沿用“已上架”实心徽标的做法），操作按钮改为主色小胶囊。宽度按内容自适应、最多屏宽减 32px，修正固定定位居中导致短句也只占半屏而换行。停留时长、悬停/聚焦暂停、点击关闭与读屏角色不变；去掉环绕 SVG 与环绕时长变量，时长改由 `data-ms` 暴露供测试；减少动态效果时只淡入淡出。
