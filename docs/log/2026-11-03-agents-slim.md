# 2026-11-03 · AGENTS.md 瘦身：界面定案原样移到独立文档

- **作者**：Claude
- **范围**：`AGENTS.md`、新增 `docs/界面与功能定案.md`、`docs/README.md`、D-039

## 出现的问题
AGENTS.md 42.8 KB，三分之二是逐条 UI / 功能定案，每次开工都要整份读入，信噪比低（两次复盘都列为待办）。

## 怎么解决的
三个定案章节原样移出（标题降一级、相对链接改为从 `docs/` 出发），AGENTS 留八条全局界面原则 + 小节索引 + 「改动前先读对应小节」；误放在售卖章节末尾的「安卓补丁约定（D-023）」归入发布与运维。用脚本比对：旧 AGENTS 每一行（忽略链接目标与标题级别）都能在新 AGENTS 或定案文档中找到，唯一不在的是被改名的章节标题。AGENTS 降到 14.9 KB。

## 可能带来的新问题
只读 AGENTS 的 agent 可能漏读定案细节；八条原则是从首份复盘第 5 节提炼的概括，不是新增规则。

## 验证
`tools/check_docs.py` 通过；逐行比对无遗漏。
