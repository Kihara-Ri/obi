# 2026-11-25 · 网页扫码完成首次安装

## 改了什么

配置 HTTPS 公网地址的新实例生成私有安装链接。管理员打开链接后，可以扫码或手动加入 Google Authenticator，再输入动态码确认。完成后进入登录页。恢复或迁移既有凭据仍走管理员终端。

## 出了什么问题

浏览器已经显示首次绑定页时，打开同路径但带 URL 片段的安装链接可能只触发同文档导航，导致页面没有读取凭据。

## 怎么解决

接收片段导航并重新进入页面，读入凭据后立即从地址栏移除。首次绑定在认证事务内校验既有所有者，成功后注销安装链接并删除链接文件。二维码在网页内生成，独立扫码解码得到同一设置密钥。

已在隔离的 HTTPS 新实例验证桌面 Chromium 和移动 WebKit 的二维码、错误提示、绑定和会话登录。Docker 新实例生成了权限为 `0600` 的链接文件，服务日志不含凭据。同步通过固定样本浏览器验收和文档检查。

## 可能带来的新问题

首次管理员需有权限读取服务器数据目录。链接 30 分钟过期，重启会生成新链接。手机相机的现场扫描由管理员操作，浏览器模拟和独立解码覆盖二维码内容。
