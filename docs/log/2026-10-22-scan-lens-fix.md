# 扫码镜头选择修复（v3.5.1，补丁）

- 根因：镜头标签形如 `camera2 0, facing back`，排序用的正则 `/(\d+)/` 取到的是「camera2」里的 2，所有镜头编号相同，稳定排序后仍是枚举的第一个，所以 v3.4.0 起「避开长焦」实际没有生效。改为 `/camera\d*\s+(\d+)/` 取真正的相机编号。
- 新增：多于一个后置镜头时显示「切换镜头 n/m」和当前镜头名，选择存 localStorage（`scan-lens`），下次优先使用。自动选不准的手机用它兜底，也方便反馈镜头名。
- 验证：Playwright 假相机 + 模拟三个镜头标签：默认选 camera2 0，点切换后记住所选。真机的镜头编号与焦段对应关系未验证（有的手机主摄不是编号最小的）。
- 只改网页，按 D-023 作为补丁发布，已装 v3.5.0 的手机免确认自动换上。
