# 页面切换改为顶栏不动的柔和过渡（v3.6.1）

- 用户反馈：切页时顶部（浮动标题）也被整幅滑走，应像专辑详情抽屉那样只有下面的内容在动，标题切换也要柔和。
- 改法：`usePageTransition.ts` 的整幅滑出 / 滑入换成快照淡出（`.page-out-soft`，150ms）+ 新页 `.page-in-soft`（顶栏组件 260ms、内容 320ms 淡入，内容带 `--soft-dx` = ±22px 位移，方向沿用 rank）。删除了顶栏 translateY 补偿与滑动用的阴影 / 层级类。库存 ↔ 展示的 fade 分支与历史驱动换页（交给系统过渡）不变；桌面与减少动态效果仍不动画。
- 验证：Playwright 手机尺寸切页逐帧截图，顶栏位置不变、内容淡入；未在真机上看手感。
