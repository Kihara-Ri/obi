# 2026-10-23 · 侧标（OBI）只在日版出现且必填

- **作者**：Claude
- **范围**：`web/src/forms/RecordForm.tsx`、`web/src/components/CopyEditionFields.tsx`、`CHANGELOG.md`、`AGENTS.md`

## 改了什么
添加 / 编辑专辑表单里，「侧标（OBI）」只在发行版确认为日版（`releaseRegion(country, pressing) === '日版'`）时出现，选项只有「带侧标 / 无侧标」（去掉「未记录」），未选时不能保存并提示。非日版不出现；保存时沿用打开时的原值（新增为空），不清除历史数据。

## 出现的问题
此前所有版本都显示侧标三选项且可保持「未记录」。

## 怎么解决的
见上。只改前端表单；服务端与批量入口（导入、批量操作）不校验，历史记录里的「未记录」保持原样，直到该日版副本被编辑时才要求补选。

## 可能带来的新问题
- 已有的日版副本侧标为空，编辑任何字段保存前都会被要求先选。
- 非日版副本若历史上有侧标值，编辑后原值保留但表单里看不到、改不了。
- 仅通过 typecheck / build，未做浏览器实测。
