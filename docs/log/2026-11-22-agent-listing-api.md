# 2026-11-22 · Agent 上架接口

- **作者** Codex
- **范围** 服务器 API、售卖草稿事务与接口文档

## 改了什么

- 服务器版可用数据目录里的独立令牌启用 Agent 上架接口。支持查在库副本、读取售卖资料与默认写作风格、下载有序原图和存回草稿。
- 复用草稿事务、照片版本校验和发行资料白名单。令牌只对这组接口有效。已有标题或正文须明确允许替换，包括旧记录里的上架描述。
- 在忽略规则和泄漏扫描里加入令牌文件名及令牌前缀。按 [Agent 上架接口](../Agent上架接口.md) 开通。

## 出现的问题

- 第一次候选测试选的专辑在样本库中只有一张库存副本。改用同时在国内和海外库存的两张 Dookie，验证返回两个独立候选。编号查询用库内的真实样本字段做精确匹配。

## 怎么验证的

- 后端 643 项测试、前端类型检查和构建、固定样本的售卖主流程与文案阅读浏览器验收通过。
- 用固定样本的日版双 CD 走实际 HTTP 接口。Codex 按条码查出副本，下载的四张版次参考图与锁定样本逐字节一致。按简洁直售写稿，保存和回读均为 200，上架标记保持未上架。
- 用 goofish-cli v0.6.6 的发布函数做断网预检。上传回执、类目和地址使用测试值，提交在本机截停，发往闲鱼的请求为零。

## 边界

- 补充或轮换令牌后须重启 Obi 才生效。真实闲鱼账号、图片上传与类目仍待线上验收。
