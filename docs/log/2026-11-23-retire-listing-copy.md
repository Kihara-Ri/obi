# 清除上架文案并恢复上架三行

- 用户圈定的范围是管理页里的上架标题和正文。管理页恢复「状态」「平台」「链接」的原有行式布局。手机识别到闲鱼商品 ID 时，链接位置使用同文案的按钮唤起商品，屏蔽系统长按菜单。
- 存储启动事务清理副本及审计数据中的 `listingDescription` 与 `listingDraft`。原草稿里的照片选择和核对元数据迁入 `listingPreparation`。清理保留副本版本、状态、平台、商品 URL 及用于上架排序的事件。账本沿用 schema 4。
- 恢复旧 JSON 或 ZIP 时同样清理文案。普通编辑和批量上架不再保存文案字段，Agent 资料包退役 `draft`，专辑 CSV 移除「上架描述」列。已存历史备份按原保留策略管理。
- 固定样本模拟旧副本及审计文案，验证启动清理的幂等性、恢复、导出和原图顺序。浏览器验收检查管理三行、原商品链接、手机跳转目标、长按菜单和上架排序。
- 后端 571 项、前端 202 项、类型检查、生产构建、Docker Compose 构建均通过。Chromium 和 WebKit 的 340 与 390 宽浅色、深色手机视口验收通过。
