# 设置 · 功能：少字、图标化、迷你手机预览

- 问题：功能模块设置是三段长文字（使用方式卡片各两行说明、整块文字标签的「界面会这样变化」、折叠的逐项开关），手机上要滚好几屏才看完。
- 改：
  - 使用方式改为一排五张图标卡（`ModulePresets`），选中项填充 + 粗边 + 角上对勾；下方一行只显示该套「适合谁」，改过开关显示「自定义组合」。
  - 新增 `ModuleTiles`：四个功能图标开关直接摆出来（不再折叠），开启 = 强调色 + 实心对勾，关闭 = 空心圈；状态变化时图标轻弹，海外周转↔购入记录的联动两块一起弹。原来「需先开启购入记录」的禁用改为点海外周转自动带上购入（toggle 原本就这样联动）。
  - 新增 `ModulePhone`：迷你手机实时演示详情管理项与手机底栏，相对已保存配置新增项弹入带「+」，将收起项虚线 + 删除线 + 「−」。
  - 原完整清单 `ModuleImpact` 与说明文字收进「全部变化与说明」折叠；保存按钮旁改为「+n −n」，均为 0 时不显示。
  - 图标集中在 `components/moduleIcons.tsx`，`core/modules` 只存键名（`ModuleIconKey`），PRESETS / MODULES / SURFACE_GROUPS 加 `icon`。
  - 文案：「保存功能选择」→「保存」，首页分段「收藏管理/收藏展示」→ 图标 +「管理/展示」，「打开应用时进入」→「打开时进入」。
- 验证：typecheck、build 通过；浏览器手机 375 宽与桌面实测，切换预设与单项开关、预览角标、console 无报错。
- 未验证：真机触感与浅色主题观感。
