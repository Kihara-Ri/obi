# 售卖识别：多服务商连接、模型与思考强度

## 改动
- 按用户要求同时保留 OpenAI ChatGPT OAuth、DeepSeek API Key、Anthropic 官方 Claude Code OAuth，保留原兼容 API；选中通道唯一，不自动转计费来源。
- 各服务商/账号/密钥隔离目录与模型/强度选择；模型从实际目录读取，已知仅文字不可选，未知图片能力保留未知。强度按能力元数据提供，默认不发参数。
- DeepSeek 私密文件保存密钥，状态 API 不返回；更换密钥清除旧目录/选择，断开明确覆盖环境变量回接。官方 Chat Completions 图片及 thinking/reasoning_effort 参数适配。
- Anthropic 通过可选官方 CLI，独立配置目录，安全模式禁用祖先 CLAUDE.md/自动记忆/插件，无工具/MCP/钩子/会话持久化。SDK 初始化拉目录，print 接收结构化图片；不读取已有个人会话或抽取其令牌。
- 任务固定启动配置与账号；Claude 授权变更/目录/推理互斥，执行前重新核验身份；取消须等待子进程退出，超时 kill 后再次等待，应用停机清理任务与登录进程。
- 凭据文件/CLI 目录忽略规则、钩子与 CI 历史扫描同步；README、使用/部署说明、D-013、组件注册表和项目规范更新。

## 问题与解决
- 独立审查发现兼容 API 切换后空 profile 覆盖环境模型；统一状态与任务的有效模型取值，增加回归测试。
- DeepSeek 断开曾回读环境密钥；增加断开 tombstone，只有显式重新连接才恢复。
- Claude 只关工具仍会发现祖先上下文；增加官方安全模式。身份检查到进程启动间可能换号；以同一操作门禁覆盖身份刷新与推理，并拒绝授权期间请求。
- 取消登录只发 SIGTERM 会留下短暂并行写凭据；增加有界 wait/kill/wait，超时清理同样在门禁内。增加线程互斥、身份变化和子进程退出测试。
- 给售卖测试副本添加参考照片会按正常照片 revision 契约使原 3D 实体过期，不能把它作为完整模型验收实例；另用独立固定样本目录和同一锁定素材包 prepare/启动校验，不绕过模型检查。

## 新风险与边界
- 真实 OpenAI/Claude 账号授权、三家实际视觉推理与品相准确性尚未验收；协议测试/目录初始化不代表账户权限、余额或实际模型成功。
- Claude CLI 为可选外部程序，默认 Docker 镜像未安装；版本/初始化协议变化会明确失败，需按部署说明安装或升级。安全模式仍遵守管理员管理策略。
- 服务商未声明图片能力时仍可能实际不支持；用户选中的模型调用失败不切其他模型或计费来源。思考强度参数正确不证明真实质量/延迟收益。
- 凭据不入业务 SQLite/JSON/数据库快照，完整目录备份仍可能包含，应按私密资料保护。进行中的模型任务不持久化，重启后需重试。
- 仅本地代码与构建产物，未提交、发布或部署；售卖范围仍为复制文案、下载选图后人工发布。
