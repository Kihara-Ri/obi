# 灯箱识别条码：取景框动画 + 编辑页就地查询

- `core/photo-barcode`：新增 `locateBarcode`（返回条码值 + 占照片的相对位置框，整图 / 分块都换算回整图坐标）。
- `LightboxScan`：识别到后在照片上显示取景框（四角括号收拢 + 脉动，周围压暗），停留约 1 秒再交出；最小 64px，避免斜条码的细线框。
- 编辑表单里点开的照片（mode=form）不再跳查询页，发 `record-barcode` 事件，`ReleaseLookupSection` 就地填入条码并查询，用来核对当前这张的发行版；详情照片墙（mode=lookup）仍跳查询页。
- 未验证：真机动画观感；框的位置只用截图离线验证了识别结果，没验证屏幕定位。
