- **作者**：Claude

## 改了什么
- 新建 Astro 静态介绍站：页眉、首屏（标语 + 被黄色腰封压着的三列漂移封面墙）、五个模块卡片、九种展示布局示意图、四条承诺、开始使用三条路径（Docker / Python / 没有服务器）、页脚。
- 颜色直接引用应用的 `web/src/styles/tokens.css`，主题跟随系统；站点只补排版与间距 token。
- 封面墙用 `site/scripts/make-covers.mjs` 生成的 12 张自制几何封面，不用开发样本库的商业封面。
- `site/tests/csp.test.mjs`：检查产物无内联脚本/样式、`.astro` 与 `.css` 无字面量颜色（ai-kit 设计检查不认 `.astro`）。
- `.github/workflows/site.yml`：`site/` 或 token 变化时构建、检查并发布到 GitHub Pages；base 路径由 configure-pages 给出。
- ai-kit 的设计、结构、日志与依赖检查扩展到 `site/src`、`site/package.json`。

## 出现的问题
- 封面墙用了 `loading="lazy"`，动画列里的图片没加载，露出空格子：去掉懒加载。
- `<img>` 的 `height` 属性压过了 `aspect-ratio`，封面上下留黑边：补 `height:auto`。
- 腰封竖排（`vertical-rl`）里 `flex-direction:column` 实际是横向，小字被挤出：改用 `row`。
- 五个模块卡片 4+1、九种布局 6+3 有残行：模块改 `auto-fit`，布局改为手机 3×3、宽屏一排九个。
- 复制按钮压住长命令：挪到卡片标题行，`git clone` 与 `cd` 拆成两行。

## 怎么验证的
- `npm --prefix site run build` + `run check` 通过；ai-kit 设计/结构检查、数据泄漏扫描通过。
- 预览 1280×820 深色、375×812 浅色逐段截图：无横向滚动，console 零报错；复制按钮在剪贴板被拒时退回选中命令。
