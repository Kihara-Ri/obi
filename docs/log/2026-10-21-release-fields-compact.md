# 2026-10-21 · 发行资料更正区紧凑化

- **作者**：Claude
- **范围**：`web/src/components/ReleaseMetadataFields.{tsx,css}`、CHANGELOG

## 问题
编辑专辑里「发行资料 · 查看及更正」展开后是十来个整行大输入框，手机上又长又空；用户几乎不手改这些字段（内圈刻码约百分之一）。

## 改了什么
- 折叠条改为虚线、弱化文案「手动更正发行资料（极少用）」，默认折叠（资料以已确认的发行版摘要为准）。
- 展开后两列紧凑布局：地区代码 / 发行日期、介质 / 碟数并排，其余整行；标签缩小，输入框更矮；手机端不退成单列。

## 验证
- 浏览器（手机宽度）：折叠条为一行虚线；展开后一屏内看全 8 个字段。类型检查、构建通过。
