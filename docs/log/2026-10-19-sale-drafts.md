# 2026-10-19 · 副本售卖草稿与照片分析

- **作者**：Codex
- **范围**：售卖草稿领域校验、storage.py 独立事务、Services 注入的照片分析/模型/官方 OAuth 服务、照片 ZIP、上架资料抽屉及设置、固定样本初始化、发布打包及文档。

## 改了什么
- 按副本分析照片标识与可见品相，保留照片编号与待确认项；条码/编号复用 MusicBrainz，不自动选版。人工核对后生成可编辑标题正文，复制后由用户手动闲鱼发布。
- 保存草稿不标记上架、不改采购金额或其他副本；显式上架与草稿同一事务。保存基于打开时 revision，照片更新后保留手写文案并清除旧证据与确认。
- 选图、排序、第一张首图、编号 ZIP，保留已有图片格式和内容，下载工具沿用应用内保存/分享。
- 优先独立官方 ChatGPT OAuth（开源 SIWC），支持多账号、PKCE、签名身份校验、续期、撤销、本机 CLI 与服务器安全导入；API 通道显式备选，失败不转计费来源。新凭据文件名与令牌模式补进泄漏防线。

## 发现的问题与解决
- 全量测试发现新增根模块没有同步更新器白名单，已同步 package_app.py、update_release.py 和 Docker COPY。
- 独立审查发现 OAuth 交换令牌期间提前结束 pending、客户端停止轮询；改为交换完成前保持 pending，增加阻塞交换回归测试。
- 独立审查发现先保存草稿再上架会在链接错误后留下已增加 revision 的半成功状态；合为单个事务，非法链接无写入且可直接修正重试。
- 独立审查发现标签刷新后旧草稿借用新 revision 可覆盖并发编辑，旧选图也可能指向更新后的照片；冻结抽屉打开时版本，刷新冲突后阻止保存/分析，图片导出仍用旧版本，由服务端拒绝错图。
