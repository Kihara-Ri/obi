# 2026-11-24 · 介绍站「开始使用」改成 CD 背面曲目表

- **作者**：Claude
- **范围**：`site/src/components/Start.astro`、`site/src/scripts/copy.ts`、`site/src/scripts/tracks.ts`、`site/src/components/Header.astro`

## 改了什么
- 「开始使用」从 2×2 卡片改成一张 CD 背面插页：四种装法是四首曲目（01 Docker · 02 Python · 03 让 AI Agent 装 · 04 手机本地使用），曲目「时长」写命令行数或交付物（4 行 / 3 行 / 提示词 / APK），点线引导到右侧。宽屏左侧有竖排侧脊（Obi · 收藏与交易账本 · OBI-0001），底部是装饰条码和小字（开源 AGPL-3.0 · 定价 ¥0 · 收藏有来处，流转有记录）。副标题前加「挑一首放进去。」
- 每首用原生 `<details name="start">` 展开，同时只开一首，默认打开 Docker；无 JS 也能展开。
- 展开和收回都有高度 + 透明度过渡（`site/src/scripts/tracks.ts`，读 `--dur-slow` / `--ease-out`，减少动效时直接开合）；脚本接管后去掉 `name`，自己负责互斥，让被挤掉的那首也平滑收回。收回期间箭头与编号先回到收起态。
- 复制按钮只用图标（两张叠放的纸），复制后变成略歪的方框盖章 + 对勾；aria-label / title 同步变成「已复制」。
- 页眉「接口」前加代码括号图标，和三个页内锚点区分。
- 命令内容未改，仍与 README「快速开始」一致。

## 出现的问题
- 原 2×2 卡片用户觉得没有新意。参照用户另一个项目「海内存知」的做法：版式和小细节从产品名本身的意象里长出来（那边是诗句、漂流瓶、弹幕），这里用 Obi 的唱片意象。
- 手机上复制按钮盖住了较长的 `git clone` 行；底部小字在「AGPL-3.0」中间断行。
- 原生 details 开合是瞬间的，用户要求展开、收回都要过渡。
- 右侧侧脊多余，用户要求去掉，只留左侧。
- 收回到最后会留一截空白再跳掉：做高度动画的 `.body` 自带 24px 下内边距，高度缩到 0 时内边距仍撑着。改为 `.body` 只做动画外壳、留白放进内层 `.inner`；逐帧测得收回时行高从 234px 连续降到 53px，中途不停顿。

## 怎么解决的
- 手机宽度下命令自动折行，右侧给按钮留位；条码与小字改成上下排、左对齐。
- 验证：站点构建与 CSP 检查通过；本地预览桌面 1280px、窄窗 615px、手机 375px，无横向滚动；单开互斥、默认展开、展开 / 收回过程中高度逐帧变化、复制成功态（预览面板无剪贴板权限时按设计退回选中代码）都核对过。

## 可能带来的新问题
- `details[name]` 互斥需要较新的浏览器（Chrome 120+、Safari 17.2+）；更旧的浏览器可同时展开多首，不影响使用。
- 条码是装饰，不对应真实编码。
