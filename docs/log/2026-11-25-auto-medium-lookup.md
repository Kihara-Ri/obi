# 2026-11-25 · 按条码和唱片编号自动识别介质

## 改了什么

「添加专辑」和「查询」默认跨介质查版次，有明确格式的候选直接显示介质。选中版次后带入格式，只有数字发行或资料缺少实物格式时才手选。查不到版次时沿用手动录入入口。

## 出了什么问题

原来的默认 CD 筛选会在扫码查询时丢掉黑胶候选。启用跨介质查询后，同号但介质不同的候选必须各自展示。

## 怎么解决

网页明确请求 `medium=auto`，条码、编号与展开专辑版本共用查询参数。查询维持精确标识匹配，介质冲突的候选各自展示。固定黑胶样本增加一个虚构 EAN，用同一张样本验收扫码与编号入口。

## 可能带来的新问题

自动查询同时查可用的多家资料库，仍受各家目录覆盖与请求时限影响。保留手动筛选、候选确认与缺资料时的手选。接口调用省略 `medium` 时沿用 CD 默认值。关联 D-053、D-055。
