## 改了什么

## 出现的问题
主工作区有进行中的 Agent 接口改动（含 README 一行「已购唱片接口」），不能动。

## 怎么解决的
在独立 worktree 分支 `docs/readme-refresh` 上基于 v3.15.0 修改；那一行由 Agent 接口的提交合入时再放进「给外部 Agent 的接口」一节。截图全部来自 `tools/preview_samples.py` 固定样本库（浅色、390×844 @2x），不使用个人数据。
