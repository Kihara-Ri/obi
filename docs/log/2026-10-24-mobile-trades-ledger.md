# 2026-10-24 · 手机端交易记录与账本排版整理

- **作者**：Claude
- **范围**：`components/SaleCard.tsx`、`pages/StatsPage.tsx`、`styles/sales.css`、`styles/stats.css`（仅 ≤840px 媒体查询内的排版；桌面不变）

## 出现的问题
手机上交易记录与账本显得凌乱：销售单首行日期 / 平台和张数挤在一起折行；每张专辑金额四行（成本 / 到手 / 金额 / 利润）；费用脚注横排折行不齐（「到手合计」挤在运费右边）；账本指标说明在词中间断开（「已上架 2」+「张」）；月度交易卡片标签在左上、数值在右下呈对角排布。

## 怎么解决的
- 销售单：首行状态 + 张数，信息行整行；金额列到手金额在上、成本与利润在下（隐藏「到手」二字以保持窄列，不挤压标题）；脚注改成「名称 … 金额」两列明细，合计行加粗并以虚线分隔；多张合单利润含待补时标签统一为「利润」，值显示「待补」（原为「利润（待补）待补」）。
- 账本：指标说明拆成段（`Note`），每段整体换行；两列网格用 `minmax(0,1fr)` 防撑破；月度卡片每个字段一行、左名称右数值。

## 验证
样本库 375×812：交易记录、售出中（含操作按钮）、账本截图检查，无横向溢出（scrollWidth=375），控制台无错误；桌面宽度截图与改前一致；前端测试通过。

## 可能带来的新问题
手机销售单的单张金额不再写「到手」字样，含义依赖页顶汇总与合计行。
