# 2026-10-24 · 折叠区展开 / 收起时内容回弹

- **作者**：Claude
- **范围**：`components/ui/Details/Details.css`

## 出现的问题
展开时内容先略微下移、动画结束又上跳；收起同理。上一次只修了标题间距，没有解决。

## 原因
正文第一个 / 最后一个子元素带外边距（如 `.rmf-unofficial{margin:4px 0 12px}`）。动画期间正文 `overflow:hidden`（成为 BFC），外边距被圈在正文内；动画结束撤掉 overflow，外边距与正文外的间距重新合并 / 穿出，布局高度和位置变化，表现为回弹。

## 怎么解决的
`.details-body` 恒为 `display:flow-root`，动画前后都是同一个 BFC，外边距归属不变；`scrollHeight` 测得的目标高度也就与最终高度一致。

## 可能带来的新问题
原先穿出正文的外边距现在留在正文内，折叠区展开后的总高度可能有几 px 差异（只增不减，不影响布局结构）。
