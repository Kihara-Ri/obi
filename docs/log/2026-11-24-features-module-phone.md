# 2026-11-24 · 介绍站「五个模块」改成真实开关 + 迷你手机

- **作者**：Claude
- **范围**：`site/src/components/Features.astro`、`site/src/scripts/modules.ts`

## 改了什么
- 「五个模块」不再是卡片，改成应用里的模块开关（外观与 `web/src/components/ui/Switch` 一致）加一部迷你手机。访客可以亲手开关，手机里的界面跟着变。
- 迷你手机照应用手机版「库存」页还原：顶栏（选择 · 标题或「库存｜展示」切换 · ＋）、国内 / 海外、统计卡、搜索、上架筛选、按月分组的列表、底部悬浮底栏（激活项是强调色胶囊，带数量徽标）。
- 各开关影响的部分与应用代码一致（`ShelfPage.tsx`、`ShelfSummary.tsx`、`core/page-motion.ts` 的 `mobileTabs`）：
  - 收藏展示：顶栏的「库存｜展示」切换；
  - 购入记录：总成本、买入价、搜索框里的「渠道」；
  - 二手交易：已上架、上架筛选、「售出中」标签；
  - 海外周转：国内 / 海外、「在途」标签，「收藏」改叫「库存」，标题「我的收藏」改为「国内库存」。
- 海外周转依赖购入记录：打开海外自动带上购入，关掉购入同时关掉海外；购入关着时海外那一行显示「含购入」（同应用模块方砖）。
- 模块名改用应用里的叫法「收藏展示」（原为「展示收藏」）。
- 示例专辑取自首屏封面墙的 30 张（夏草が邪魔をする、One Last Kiss、In the Court of the Crimson King、Life Continues），价格是演示数据。

## 出现的问题
- 先后试过「带腰封的 CD」：用户认为唱片 / 腰封意象在站里用得太多（首屏、开始使用都有），要求换一种。
- 第一版迷你手机只是骨架加「一个模块一个标签」的底栏，和应用实际的底栏不符（应用底栏是 库存 / 在途 / 售出中 / 更多，展示是顶栏切换）。用户要求还原手机实际 UI。
- 底栏图标用 `set:html` 注入，Astro 作用域样式不作用于注入内容，图标被渲染成黑块。

## 怎么解决的
- 用示例数据启动应用（`tools/preview_samples.py`），在 390px 手机宽度下对照真实库存页逐项还原，显隐规则直接对照源码。
- 显隐用纯 CSS `:has()`；块级内容用 `grid-template-rows` 0fr/1fr 平滑收起，底栏标签用 `flex-grow` 收起。依赖联动放在外部脚本 `modules.ts`（CSP 不允许内联脚本）。
- 注入的图标样式改用 `:global(svg)`。
- 验证：构建与 CSP 检查通过；1280px 下逐个组合核对（全开 / 关展示开海外 / 全关），依赖联动正确；375px 手机无横向滚动。

## 可能带来的新问题
- 迷你手机是静态还原，应用库存页改版后这里要同步改（源码注释已注明对照文件）。
- `:has()` 需要较新的浏览器（Chrome 105+、Safari 15.4+、Firefox 121+）；更旧的浏览器上开关能拨，但手机不跟着变。
- 发现一个原有问题（未改）：站点构建把页眉的 `backdrop-filter` 压成只剩 `-webkit-` 前缀，Chrome 里页眉毛玻璃没有生效。
