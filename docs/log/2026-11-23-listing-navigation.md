# 管理页商品入口与上架排序

## 变更

- 管理页撤下上架状态、平台和历史文案，保存了商品链接的副本显示一个商品按钮。按钮禁用长按菜单。手机点击「打开闲鱼」时，根据已存链接中的商品 ID 导航到闲鱼移动商品页。桌面和其他平台打开已存网页。
- 库存「已上架」可以选择「最近上架」或「最早上架」。排序由完整审计推导，使用闲鱼回执的在线核对时间或手动标记时间。同一时间按审计顺序排列，缺少历史依据的记录排在最后。
- 整理库存结果、专辑数据类型及抽屉样式的文件归属。

## 验证

- WebKit 触屏测试发现下拉选项取消 `pointerdown` 会吞掉点按。改为在 `mousedown` 保持下拉焦点后，Chromium 与 WebKit 的 340 和 390 宽浅色及深色验收通过。
- 固定样本验证历史商品网页、原图 ZIP、两种排序方向、列表与卡片、商品按钮的长按事件和准确的跳转目标。后端 573 项、前端 202 项、类型检查、生产构建、固定样本启动和 Docker Compose 构建通过。
- 已核对闲鱼移动商品页与平台的 App 关联配置。验收拦截虚构商品链接。iPhone 真机离线，系统实际唤起和系统长按行为待确认。[iOS 关联](https://h5.m.goofish.com/.well-known/apple-app-site-association) · [Android 关联](https://h5.m.goofish.com/.well-known/assetlinks.json)
