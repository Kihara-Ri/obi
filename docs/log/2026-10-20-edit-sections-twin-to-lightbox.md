# 2026-10-20 · 编辑页分区重排；数字实体迁到展示灯箱「实体设置」（D-015 第二步）

- **作者**：Claude
- **范围**：`web/src/forms/RecordForm.tsx`、`forms/record/ReleaseDetails.tsx`（拆出 `PackageReview`）、`components/TwinControls.tsx`、`components/GalleryFocus.tsx`、`styles/gallery-focus.css`、`tests/twin-controls.test.mjs`、`AGENTS.md`、`部署说明.md`、`使用说明.md`、`README.md`、`docs/DECISIONS.md`

## 改了什么
- **编辑页分区**：实物照片 → 专辑资料（发行版查询与状态、「发行资料 · 查看及更正」折叠、专辑名 / 艺人、封面）→ 这一张（包装结构待核对确认、侧标、存放位置）→ 购买信息（行式：金额、日期、额外费用、渠道、新增时入库位置）→ 备注。去掉底部的「数字实体」。包装确认下拉是副本层，从 `ReleaseDetails` 拆成 `PackageReview`。
- **数字实体迁到展示灯箱**：灯箱右上角新增「实体设置」按钮（有实体或有任务时出现），点开底部面板，内容复用 `TwinControls`（状态、补充 / 移除独立附件、校准盘面）；面板画在 `<dialog>` 内部（灯箱是 top-layer，抽屉不可见）；Esc 先关面板再关灯箱；换张自动收起面板。
- `TwinControls` 新增 `onSettings`：引擎未安装时「打开设置」在灯箱里直接跳转（卸载灯箱），在别处仍走抽屉的先收后跳。状态文案由「已有数字实体，可在收藏展示中查看」精简为「已有数字实体」。
- 文档：AGENTS.md（两处）、部署说明、使用说明、README 中「数字实体入口在编辑表单 / 编辑专辑」改为展示灯箱「实体设置」；D-015 状态更新为已实现。

## 出现的问题
- 灯箱是 top-layer `<dialog>`，一开始想沿用抽屉打开实体设置会被盖住，改为面板内置在灯箱里。
- `twin-controls.test.mjs` 追加了源码级断言（编辑 / 详情 / 管理不再含 TwinControls，灯箱含 TwinControls 与 `onSettings` 跳转）；该文件原来没有 `fs` 导入，补上。

## 怎么解决的
类型检查、构建、前端 128 项测试、后端 453 个测试通过。iPhone 模拟器：编辑页新分区顺序；展示灯箱中打开「实体设置」，面板内可展开「补充或移除独立附件」（样本实体提示无可复用图集，属数据本身）。

## 可能带来的新问题
- 展示模块未启用时没有展示页，也就没有数字实体的入口（D-015 已预见；已有实体的数据保留，不受影响）。
- 灯箱里没有实体也没有任务的专辑不显示「实体设置」，用户看不到「还没有数字实体」的提示；若需要可改为一直显示。
- 面板在窄屏占 70dvh，打开校准编辑器时可用空间较小，未在真机验证。
- 未部署。
