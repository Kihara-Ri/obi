# 2026-11-25 · 塑料盒包装图标改成正面平面画法

- **作者**：Claude
- **范围**：`web/src/components/PackagingIcon.tsx`、`CHANGELOG.md`

## 改了什么
- 标准塑料盒、薄塑料盒、多碟塑料盒三个图标原来是带顶面和侧面的立体盒，和纸套、折页等正面平面图标风格不一致。
- 改成同一种正面画法：左侧铰链条 + 盒盖下的光盘；厚度用身后错开的边表示（和 digibook 的书背同一手法）：薄盒没有，普通盒一层，多碟盒两层。图形在画布里居中。

## 出现的问题
- 新建专辑表单里包装选择要先查询或切到手动录入才出现，浏览器里不便逐个比对。

## 怎么解决的
- 用 esbuild 把 `PackagingIcon` 全部种类渲染成一张对照表，在预览里并排检查；对照表放在会话临时目录，不进仓库。
- 验证：`web` typecheck、build 通过。

## 可能带来的新问题
- 只改图形，不改包装取值与识别逻辑；`slimline` 现在与 digipak 右半边同为「方框 + 光盘」，靠左侧铰链条区分。
