# 外部客户端只读查找已购唱片

- 新增 `GET /api/collection/purchases`。单独设置查询令牌后，授权客户端按艺人、专辑、编号或条码检索可确认的购买记录。复用上架查询的匹配规则，持有、在途、售出中、已售和已移除各有状态。接口只提供唱片资料和副本状态。
- 新增副本时日期和渠道可以被预填，售出也不能证明曾购。查询使用正数买入金额或实际支出作为依据。旧记录未记金额时可能无法命中，缺少的介质或版次资料保持未知。
- 固定样本 HTTP 测试覆盖全状态、独立令牌、字段白名单、条码和编号、分页与停用。验证使用临时目录中的虚构账本与临时令牌。
- 按接口文档新建权限为 `0600` 的令牌并启动固定样本，用 curl 读回示例响应。后端 582 项、前端 202 项、前端类型检查及生产构建通过。隔离 Docker Compose 构建和容器内的 Python 3.12 路由、SQLite 投影检查通过。
- Chromium 通过上架和照片下载验收。Chromium 与 WebKit 通过商品入口、上架排序和手机批量填报验收。
- 盘点服务器路由、授权和读写范围，登记独立的 HTTP 接口索引。
- 以本次源码快照发布构建 `v3.15.0-1-g8c246e8`。发布前快照已核实，账本结构保持 4。公网健康检查通过。虚构检索词在正确令牌下返回 200，缺失或错误令牌返回 401。上架、交易和应用接口继续各自鉴权。
