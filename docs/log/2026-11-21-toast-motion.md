# 2026-11-21 · 顶部提示的出现与消失动效

- **作者**：Claude
- **范围**：`web/src/components/ui/Toast/Toast.tsx`、`Toast.css`

## 出现的问题
- 用户反馈：顶部「已保存」这类提示弹出和消失时太生硬，需要改进。原来只是原地上移 10px 淡入、上移 8px 淡出；连续两条提示时旧的直接消失、新的重新弹出，像闪了一下。

## 改了什么
- 出现：从屏幕顶端外带一点回弹落下（原点在顶边，由小放大），左侧圆点随后弹出，✓ 一笔画出，文字轻微右移淡入。
- 消失：缩小、收回顶端并淡出（0.26 秒，加速离场）；淡出中不再接收点击。
- 上一条还在显示时来了新提示：不再整条重新落下，原地轻轻一缩一弹换成新内容。
- 减少动态效果时只做淡入淡出，✓ 直接显示。

## 怎么验证的
- 示例预览手机尺寸：确认签收触发「已保存」，按时间点冻结帧截图（60 / 160 / 300 / 420 / 620ms 出现，消失两帧）。测完示例数据已恢复。
- 前端单测、类型检查、构建、后端测试、文档检查、浏览器验收。

## 可能带来的新问题
- 落下动画比原来长（0.52 秒）；提示停留时长不变。
