# 2026-11-21 · 售出中、交易记录、海外在途也有「封面飞向去处」

- **作者**：Claude
- **范围**：`web/src/pages/cardFly.ts`（新，从 useListFlip 拆出）、`web/src/pages/useListFlip.ts`、`ShelfPage.tsx`、`ShippingPage.tsx`、`TradesPage.tsx`、`TransitPage.tsx`、`SaleCard.tsx`、`ShipmentCard.tsx`

## 出现的问题
- 用户反馈：库存里售出时封面会飞向「售出中」，但售出中确认收货、撤销，在途包裹签收、回滚签收都没有过渡动效。

## 盘点（状态变化 → 去处）
| 在哪一页 | 操作 | 原来 | 现在 |
|---|---|---|---|
| 库存 | 售出 / 打包运输 / 调动 | 有 | 不变 |
| 库存 | 删除 | 原地淡出 | 封面飞向回收站入口（手机「更多」、桌面「设置」） |
| 回收站 | 恢复 | 有，但手机库存标签指向另一边时找不到入口 | 找得到 |
| 售出中 | 确认收货 | 无 | 封面飞向交易记录（手机「更多」） |
| 售出中 | 撤销售出 / 未发货退款 | 无 | 飞回原库存 |
| 售出中 | 退货 | 无 | 飞向国内库存 |
| 售出中 | 仅退款 | 无 | 飞向交易记录 |
| 交易记录 | 撤销退款 | 无 | 飞回售出中 |
| 海外在途 | 确认签收 | 无 | 封面飞向国内库存，包裹平滑挪到「最近签收」 |
| 海外在途 | 回滚签收 | 无 | 包裹平滑挪回在途列表 |
| 海外在途 | 撤销运输 | 无 | 封面飞回海外库存 |

## 改了什么
- 飞行逻辑拆到 `cardFly.ts`；`useListFlip` 改成可指定卡片选择器与去处函数，售出中、交易记录、海外在途接入。
- 多张专辑的销售单 / 包裹每张封面都飞（最多 5 张，依次错开）。
- 卡片还在、专辑却换了去处（包裹签收后留在「最近签收」）也会飞封面。
- 找入口：手机上交易记录、回收站落到「更多」；库存标签指向海外或国内哪一边都认。

## 怎么验证的
- 示例预览手机尺寸：在途确认签收，5 张封面飞向底栏「库存」，包裹挪到最近签收；回滚签收挪回；售出中确认收货，封面飞向「更多」，卡片淡出。测前数据已备份，测完恢复。
- 前端单测、类型检查、构建、后端测试、文档检查、浏览器验收。

## 可能带来的新问题
- 销售单的去处按第一张专辑判断；同一单专辑去处不同（极少）时都飞向第一张的去处。
