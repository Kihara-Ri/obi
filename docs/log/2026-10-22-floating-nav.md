# 手机底栏改成悬浮岛（v3.5.4，补丁）

- 范围：`AppNav.tsx`（MobileNav）、新增 `navIcons.tsx`、`styles/layout.css`、展示页与批量条的底部留白（`gallery-viewport.css`、`BulkBar.css`）。
- 设计：底栏离边缘 12px / 10px、58px 高的圆角玻璃条；激活标签是强调色胶囊，展开图标 + 文字，其余只有图标。导航用 grid 列宽（激活权重 2.3、其余 1）过渡，胶囊的 left / width 用同一套权重和同一过渡，二者同步。气泡放在图标上，激活时改到胶囊右端并给内容让位。
- 注意：激活标签的图标不能带 transform，否则会变成气泡的定位参照而把它拽回图标旁（第一版踩过）。
- 验证：Playwright 手机尺寸深浅两色，切换前 / 中 / 后截图。只有两个标签（库存 + 更多）的情形看过；展示、在途、售出中都开启的五槽情形没有在真机看，文字长度最长的「售出中」在激活胶囊里应放得下，但未实测。

## v3.5.5 下移
- 用户反馈位置偏高：底栏距底改为变量 `--nav-bottom = max(8px, 安全区 − 14px)`，展示页底部留白与批量条跟着它算。iPhone 上约 20px。只用浏览器无法模拟安全区，位置未在真机上看过。

## v3.5.6 页眉同款
- `.page-head`（手机）改为悬浮岛：`--head-top = max(10px, 安全区顶 + 4px)`，吸顶位置与首屏位置同由它决定；`::before` 是岛上方到屏幕顶的渐隐底（高度只到岛的上沿，避免盖住玻璃本体）。浏览器里看过深浅两色与返回钮页；安全区与真机刘海位置没法模拟，未在真机看过。
