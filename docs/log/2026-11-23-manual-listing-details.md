# 默认最近上架并支持手动编辑上架信息

- 「已上架」第一次进入按最近上架排序。它和常规库存筛选各自使用所选排序，国内与海外切换时和上架筛选一起保留。
- 详情、手机左滑和批量入口共用平台和链接表单。已上架的库存副本在管理页编辑。平台与链接可留空，批量时共用平台且逐张填写链接。
- 表单提交记录打开时的副本版本。存储层在同一事务中按状态与版本检查所有副本，闲鱼商品编号仍绑定对应的实物副本。编辑使用独立审计动作，排序取当时的上架事件。
- 固定样本验证默认排序、单张登记和编辑后读回，以及手机批量分别保存链接。后端 574 项和前端 202 项测试通过。类型检查、生产构建、Docker Compose 构建、固定样本启动、Chromium 与 WebKit 浏览器验收通过。
