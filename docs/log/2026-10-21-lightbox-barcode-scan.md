# 详情里点开条码照片 → 识别并直接查询

- 需求（再次纠正）：在详情里点开有条码的那张照片，选项让应用内部识别这个条码并直接搜索，省去抄数字。
- 做法：详情照片墙打开的灯箱里加「识别条码并查询」（`components/ui/LightboxScan.tsx`），用 `core/photo-barcode`（与相机扫码同一识别器）读当前这张；识别到有效条码 → `core/lookup-handoff` 交给查询页 → 关闭抽屉与灯箱跳到「查询」并直接搜索。识别不到在灯箱里提示，可翻到另一张再试。
- 撤销：移除误解的产物——详情「显示条码」按钮、`BarcodeSheet`、`core/ean.ts` 及其测试与 token。
- 保留：录入 / 编辑表单里条码为空时从照片自动识别（上一轮）。
- 未验证：真机整条流程；条码占比很小的照片。
