# 跟随系统时同步更新深浅配色

- iPhone 截图里的抽屉底色已是深色 `#161920`，标题和字段值仍是浅色主题字色 `#1e2430`，编辑按钮已是 `#e8ebf1`。固定样本在 WebKit 连续切换系统外观时复现同样的颜色组合。
- 系统外观事件原先会打开全页颜色渐变。外观变化重叠时，抽屉底色和继承的字色各自过渡，结束时间不同。现在启动和跟随系统直接读取 CSS 配色，设置里主动切换时仍有原来的淡化。
- 浏览器验收检查系统切回深色的第一帧，核对管理抽屉的底色、标题和字段值。该检查在旧版上失败。
- Chromium 与 WebKit 回归通过，并核对了固定深色与跟随系统的启动首帧和主动换色。iOS 27 模拟器上的 Safari 完成固定样本启动和切回前台检查。后端 574 项、前端 202 项测试及生产和 Docker Compose 构建通过。
