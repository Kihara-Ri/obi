# 2026-11-12 · 表单保存失败提示定位

## 问题与处理

多个抽屉的错误位于滚动内容顶部，用户在底部点保存时看不到；手机金额输入层的只读入口也会被原生校验跳过。增加共用字段提示与抽屉内定位，发行版、包装、侧标与原生字段在相应位置显示错误；服务端和等待类提示放到底部操作区。修正字段后清除提示，不强制聚焦或弹键盘。每次保存失败提示轻抖一次（减少动态效果时改为淡入），连续点击也能看出按钮有反应；字段提示序号改为只增计数，避免先清再显被批处理后不重播。未改变专辑数据和既有业务必填条件。

## 验证与风险

固定样本浏览器验收覆盖手机、桌面、连续缺项、包装、侧标、只读金额框、模拟保存失败与修正；另在隔离样本中验证失败后重试保存成功。前端 184 项、后端 623 项、类型检查、构建与 Docker Compose 构建通过。浏览器模拟不代替手机真机键盘和手势验证。
