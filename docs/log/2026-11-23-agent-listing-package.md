# 上架资料包与内置售卖工具退役

## 变更

- D-047 移除手工上架表单、售卖 AI 和浏览器里的服务商配置。专辑管理页提供历史上架信息、链接和可复制的旧文案。库存上架标记、销售单和 D-046 的三项写接口沿用原有逻辑。
- `GET /api/listing/agent/package` 用一个只读令牌完成副本查找与 ZIP 下载。资料清单与照片共用一次读取的版本，保留有效的历史选图与顺序。旧草稿继续按原格式保存和恢复。
- 详情照片下载迁到普通照片路由。新网页不调用安卓原生模型中继，旧外壳继续兼容。应用升级无需迁移业务数据。

## 验证

- 原浏览器验收的登录门由样本服务显式关闭。恢复这一配置后，Chromium 首次验收覆盖原图 ZIP、历史文案与链接及账户页。Chromium 和 WebKit 的手机与桌面尺寸验收覆盖长文布局，Chromium 另验证完整复制。
- 后端 572 项、前端 202 项测试通过。类型检查、网页生产构建、本机模式打包、Docker Compose 构建和治理文档检查通过。
- 固定样本 HTTP 验收校验四张版次参考照片的原始字节。登记在线回执与付款后，先报到账、再报收货，销售单按到账日期完成。重发两种事实仍只有一笔销售单。
- 旧集成需要改用资料包地址，在外部保存新草稿。发布和订单事件由外部系统提供。样本验收使用虚构交易，生产验收只检查健康、权限范围和无效请求。
