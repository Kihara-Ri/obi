# 封面燃烧显现（v3.6.2）

- 用户反馈：查询页「找封面…」之后真实封面瞬间出现，希望像火蔓延、从边缘逐渐变成完整封面。
- 做法：`core/burn-reveal.ts`。图片 `onLoad` 时（仍 hidden）生成 40×40 的「着火时刻」图（离边越近越早 + 平滑噪声），逐帧把透明度画进小画布，转成 CSS mask 套在封面上；另有一块同尺寸叠加画布画橙黄余烬（screen 混合）。约 950ms 后清掉 mask 与叠加层。每个 img 元素只播一次；减少动态效果或不支持 mask 时直接显示。不读写跨域图片像素，不影响 `useArtExpand` 的放大动画。
- 验证：Playwright 合成封面逐帧截图，火线由边缘向中心推进、最终完整；未接真实 CAA 网络与真机验证。

- v3.6.3：v3.6.2 提交与发布包里的 `static/` 是改源码前构建的，没有该效果。发布流程必须先 `npm --prefix web run build` 再提交、打包（改完源码不构建等于没改）。

- v3.6.4：用户实机反馈封面一直「找封面…」。`onLoad` 里把 `setArtState('ok')` 放到动画之前，`burnReveal` 整体 try/catch（出错清掉 mask 直接显示），并加 rAF 暂停时的兜底清理。动画是装饰，绝不能挡住封面状态。

- v3.6.5：手机网络下 CAA（两次跳转）请求会既不 load 也不 error，卡在「找封面…」。`ReleaseCandidateCard` 加了就绪检查（`img.complete`）与 8 秒超时重试（key 变化 + `?r=n`，相同网址会被浏览器并入挂住的请求），最多 3 次后按无封面。本机用「首个请求挂住」模拟验证了恢复；仍无法确定真机上是否由此引起。
