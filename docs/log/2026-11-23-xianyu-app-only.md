# 手机闲鱼商品入口只唤起 App

- iPhone 真机反馈点按后仍出现闲鱼移动商品页。固定样本中让页面一直保持前台，旧版在 1.5 秒后请求 `https://h5.m.goofish.com/item?id=1004`，复现同一跳转。
- 删除定时器和页面事件监听。按钮在点按手势内只提交对应商品的 App 地址，唤起未完成时保留管理页。商品地址继续使用闲鱼商品页二维码的路由。 [闲鱼商品页脚本](https://g.alicdn.com/idle-pc/xy-site/0.0.187/js/p_item-index.js)
- Chromium 和 WebKit 验收覆盖切后台返回、始终留在前台与再次点按。每次点按只有一次 App 协议调用，商品网页请求为零。后端 574 项和前端 202 项测试通过。类型检查、生产构建、固定样本启动与 Docker Compose 构建通过。iPhone 系统交接由真机确认。
