# 安卓 v3.5.0：安装包更新不再自动装

- 用户实测 v3.3.0 仍显示「离开应用后自动安装」。原因：v3.4.0 的按钮只覆盖手动检查，自动下载的更新仍走离开应用静默安装。
- 改动：`Updater` 删除后台 / onStop 静默安装路径，下载好只在前台弹确认，设置页给「安装」按钮；`MainActivity.onStop` 不再触发安装；设置页文案同步。补丁（网页内容）不受影响。
- 注意：手机上已装的 v3.3.0 / v3.4.0 带旧逻辑，升到 v3.5.0 这一次仍可能在离开应用时自动装；之后才是点击安装。
- 验证：debug 包编译通过、前端 typecheck 通过；未在设备上走完整流程。
