# 展示聚焦：手机去掉左右按钮，改左右划动切换

- `gallery-focus.css`：≤600px 或触屏下隐藏 `.gallery-focus-nav`（遮挡画面）；桌面保留。
- `GalleryFocus`：touch 手势——横向位移 ≥48px、横向占优（≥竖向 1.5 倍）、<700ms 才算；左划下一张、右划上一张，沿用原 `navigate`（收回-放大过渡）。3D 模式、实体设置面板、2D/3D 开关上的手势不触发。
- 切到别的专辑时，把下层对应缩略图 `scrollIntoView`（竖向居中、横向就近），收回时有地方落；横向轨道类布局仍由它们自己的 currentId 逻辑居中。
- 未验证：真机手势手感；各布局（瀑布 / 桌面 / 轨道 / 轮转）下层同步的实际位置。
