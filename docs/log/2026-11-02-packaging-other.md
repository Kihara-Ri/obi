# 2026-11-02 · 包装选择加「其他」，并重画盒类图标

- **作者**：Claude
- **范围**：`web/src/components/PackagingIcon.tsx/.css`、`forms/record/ReleaseDetails.tsx`（`PackageReview`）、`web/tests/album-packaging.test.mjs`、`REGISTRY.md`、`CHANGELOG.md`

## 出现的问题
1. 包装预设只有 10 种，有的实物归不进任何一类，只能硬选最接近的，信息失真。
2. 三种塑料盒与硬纸盒的图标是「盒中盒」线框，不像实物，也不如纸套图标精致。

## 怎么解决的
1. 选择卡新增「其他」：选中存为 `Other`（`packagingKind` 判为 other，显示「其他包装」），并清掉旧预设的结构字段、保留照片映射，保持 2D、不生成 3D。资料库带来认不出的原值同样归在这张卡，选中不会覆盖原值。曾做过自由描述输入框，用户改为只要归到「其他」即可，已去掉。
2. `PackageReview` 始终同一棵 Details 树：缺包装时强制展开。
3. 塑料盒图标改为正面带铰链条与光盘的立体盒，厚度 1.5 / 3 / 5.5 区分薄 / 标准 / 多碟，多碟侧面加托盘分层线；硬纸盒改为天地盖（盖子略宽出一圈）。

## 可能带来的新问题
- 历史自由文字包装仍显示为原文并归在「其他」。
- 没有做「接近哪一类 + 缺陷标签」的结构化字段（会改数据语义，需先确认口径）。

## 验证
前端 typecheck / build / 174 项测试通过；固定样本库浏览器放大查看新图标，编辑抽屉选「其他」保存正常。未做真机验证。
