# 手机上切页不压历史（避免 iOS 左缘右划退回上一页）

- Web 无法禁用 iOS 浏览器从屏幕左缘右划「返回」的系统手势；能做的是让它无处可退。
- `core/nav.ts`：手机宽度（≤840px）下切页一律 `location.replace`，不往历史栈压条目；全局拦截页面内 `#锚点` 点击（抽屉里的链接除外）与代码里原先的 `location.hash =`。桌面仍走正常历史，浏览器后退键可用。
- 抽屉、展示聚焦照旧压条目（右划 = 关闭它们，是想要的行为）。
- 取舍：手机上不能再用后退 / 右划在页面之间返回，只能点底栏 / 顶栏。
- 未验证：真机 iOS Safari 与主屏幕 App 里右划的实际表现。
