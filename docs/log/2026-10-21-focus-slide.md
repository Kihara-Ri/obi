# 展示聚焦：切换改为横滑、封面跟手

- 问题：切换专辑时封面缩回原缩略图再从新缩略图放大；缩略图不在视口里就错位 / 退化成淡出。
- 改：切换（拖动、方向键、桌面按钮）一律横滑——当前封面滑出，下一张从另一侧滑入（`slideOut` / `slideIn`，200ms）。缩放过渡只留给打开 / 关闭。
- 手机拖动跟手：横向位移直接作用于封面（带轻微淡出），够远（min(110px,25%宽)）或快速甩动松手切换，从松手位置接着滑；不够则回弹；到头有阻尼。3D / 实体设置面板 / 2D-3D 开关上的手势不触发。
- 保留：切换后下层缩略图 scrollIntoView，关闭时的缩回有落点；落点仍不在视口则淡出。
- 未验证：真机手感、各布局。
