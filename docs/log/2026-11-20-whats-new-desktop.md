# 2026-11-20 · 更新说明弹窗：桌面端放宽

- **作者**：Claude
- **范围**：`web/src/components/WhatsNew/WhatsNew.css`

## 改了什么
- 桌面端（宽于 840px）的更新说明弹窗从 420px 放宽到 640px，最高 760px；内边距、字号、行距和条目间距都相应放大。
- 桌面端的「知道了」按钮放在右下角、常规大小，不再整行铺满。手机端保持不变。

## 出现的问题
- 截图反馈：桌面端的更新说明和手机一样窄。原因是宽度写死为 `min(420px, 100vw - 32px)`，没有桌面断点。

## 怎么验证的
- Playwright 让本地服务返回 v3.14.0 来弹出窗口：1440 宽下弹窗 640×760、居中；390 宽下仍是 356px，与原来一致。
