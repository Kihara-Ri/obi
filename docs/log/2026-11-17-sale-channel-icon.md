# 2026-11-17 · 销售单卡片：售出平台改为图标

## 问题与处理

用户要求优化售出中卡片，先把售出平台（「闲鱼」文字）改成图标。复用买入渠道已有的 `ShopMark`（`components/ShopField.tsx`，品牌图标来自 `shopIcons.ts`，含闲鱼），在 `SaleCard` 日期行最前面显示 16px 图标，平台名从文字信息里去掉；包一层 `role="img"`、`aria-label="平台 X"` 与 `title`。没有内置图标的平台显示首字母方块。售出中与交易记录共用这张卡片，一并生效。`界面与功能定案.md` 已补条目。

## 验证与风险

前端 190 项、类型检查与构建通过。样本手机视口（深浅两色）拦截状态接口把平台换成闲鱼截图核对：图标 16×16 与日期同行，读屏名称正确，控制台无错误；未拦截时示例平台显示首字母方块。真机上图标与文字基线对齐需看一眼。

## 追加：卡片收紧四项

用户同意继续优化售出中卡片，四项都做：售出中用「已 N 天」徽标代替「售出中」标签（`LONG_WAIT_DAYS` = 7，超过变 `--orange` 提醒色），日期行不再重复天数；费用三行收成一行 `.sale-fees`，每项不断开、项间空格作折行点（日元折算文字长，首版空格包在不折行的段里导致 360px 下溢出，已修）；操作改为「⋯」+「退款 / 退货」+「确认收货」，「修改费用」「撤销售出」放进 `openSaleMore` 贴底面板（沿用抽屉栈，进入表单后取消回到面板）；单张不显示张数。新增共享图标 `MoreIco`。已确认收货的卡片仍直接显示「修改费用」。样本手机视口：单张售出中卡片高度由约 363px 降到 259px；深浅两色、「⋯」面板进入修改费用、交易记录页日元合单无溢出，控制台无错误；前端 190 项、类型检查与构建通过。

## 追加：统计卡片

用户要求顺带优化售出中顶部统计卡片。原样式是「5 张专辑 5 个销售单 预计到手 预估利润」一串同字号文字，折行后零散，张数与笔数常常重复。改为 `.sale-summary`：预计到手、预估利润两个 22px 大数字并排，分隔线下一行笔数（张数不同才补）、超过 7 天的笔数（提醒色，阈值从 `SaleCard` 导出共用）、成本待补张数。只改售出中页，其他页的 `.summary` 不动。样本手机视口深浅两色与 340px 窄屏无溢出，控制台无错误；前端 190 项、类型检查与构建通过。

## 追加：徽标与日期并一行

用户同意把手机上卡片首行的「已 N 天」/ 状态徽标与日期行并成一行。`sales.css` 手机断点里 `.sale-top .info` 不再 `flex-basis:100%` 独占一行，改为与徽标同行、在自己的格子里折行；张数与备注（合单、有备注时才有）放到下一行。`SaleCard` 把日期信息拆成逐项不折行的片段，只在「 · 」处换行，避免 340px 窄屏把单号拆成「DEMO-」「1001」。样本手机视口：无备注的单张售出中卡片高度由 259px 降到 237px；深浅两色、340px 窄屏与交易记录日元合单均无溢出，控制台无错误。
