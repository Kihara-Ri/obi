# 2026-11-17 · 手机切页空间过渡

## 问题与处理

用户要求切页有明确的页面状态和空间感：底栏之间按图标左右位置决定方向，「更多」里的子页进入时底页先凹下再出子页，退出反向。原实现用写死的 `PAGE_RANK` 比大小，底栏随模块与默认首页变化时方向可能与图标位置相反，子页与平级切换共用一条轴；安卓返回键走历史，被当作系统过渡跳过，没有退出动画。先做了可对比的动效样稿，用户选定推荐组合（景深平移 + 顶栏不动 + 右侧推入）。新增 `core/page-motion.ts`：底栏顺序（`MobileNav` 改用同一份）与两页关系判定（none / switch / tab / push / pop）；`core/page-transition-play.ts` 用 Web Animations 播三种动画，仍沿用 DOM 快照作旧页。历史驱动的换页只在「退一层」时播放；左缘右划时垫底页随进度从凹下恢复。新增 `--recess-bg` token，`界面与功能定案.md` 对应条目已改写。

## 验证与风险

新增 `tests/page-motion.test.mjs`（底栏顺序、方向、推入 / 弹出、子页点标签、库存↔展示）；前端 189 项、类型检查与构建通过。固定样本手机视口深浅两色逐帧冻结核对横向切换、推入、返回钮弹出，模拟安卓无点击历史返回播放弹出，推入途中切标签后无残留快照、遮罩与动画，控制台无错误。浏览器模拟环境被识别为 iOS，安卓真机返回键、iOS 左缘右划跟手的凹下恢复与低端机帧率需真机确认；Chrome 安卓浏览器（非应用外壳）若启用系统返回动画，退一层可能出现双重过渡。

## 追加：改选平移视差与「更多」样式

用户对景深平移不满意，改选样稿里的「平移视差，整页一起动」：快照垫在 #shell 下退后压暗，新页带阴影整幅滑入。按样稿改了 UI：「更多」改为分组（工具 / 记录 / 管理）圆角卡片与图标块（外观行组件不动），国内 / 海外改为分段控件，手机顶栏标题去掉玻璃胶囊、顶部底色盖到顶栏下沿。顺带修正 #main 过渡类名拼成 `page-poping` 导致弹出底色样式不生效。浏览器面板隐藏时动画时间线不走，收尾靠 1.2 秒兜底，需前台/真机确认。

## 追加：左右切页「瞬间一跳」

用户反馈左右切换不自然、像瞬间一跳。无头浏览器逐帧采样（4 倍降速）帧间隔均匀，没有掉帧；问题在曲线：强缓出 `cubic-bezier(.2,.8,.2,1)` 让新页在前 4 帧就走完约六成屏宽，之后 300ms 只挪最后几像素。横向切换改为缓入缓出 `cubic-bezier(.4,0,.2,1)`、460ms，旧页压暗降到 0.5；推入 / 弹出不变。真机观感仍需确认。

## 追加：进出子页同样一跳；切页时旧页闪一下

推入逐帧采样同样是强缓出：底页在头 4 帧就凹完，子页 5 帧冲过六成屏宽。推入 / 弹出也改为缓入缓出 `cubic-bezier(.4,0,.2,1)`（420–460ms），底页凹下只动 transform、圆角改为常驻样式，动画可交给合成线程，子页首次渲染卡住主线程时不再停顿。旧页闪烁：快照克隆里的 `<img loading=lazy>` 插入时尚未完成，先画空白再出现；克隆图片改为立即加载、同步解码，实测插入时全部完成。真机观感仍需确认。

## 追加：旧页封面仍闪一下

用户反馈仍闪。CDP 逐帧录屏（3 倍降速）看到：即使克隆 `<img>` 已 `complete`，换页第一帧封面仍画成空白，下一帧才出现。新增 `core/ghost-images.ts`：抓快照时把视口内已加载的封面换成按原图（含 object-fit）画好的 canvas，不再依赖克隆图片重新解码；跨域图片只会污染 canvas，不影响显示。库存↔在途来回录 4 次，旧页与新页封面在所有帧都在；前端 189 项、类型检查、构建与治理文档检查通过。真机观感仍需确认。

## 追加：其余过渡按样稿推荐补齐

闪烁确认解决后，用户要求其余过渡按样稿推荐做好。对照样稿逐项补齐：推入改为样稿节奏——底页先凹（340ms）、子页晚 110ms 再从右侧盖上（440ms），弹出倒放（子页 360ms 滑走、上一级晚 120ms 恢复），曲线仍用已确认的缓入缓出；减少动态效果从「不做动画」改为样稿的 120ms 交叉淡化（`playFade`，`.page-ghost-fade`）；子页返回钮改为样稿的「‹ 上一级名」纯文字钮。录屏发现旧页顶栏会比内容早一拍冒出新页的返回钮（`PageHead` 直接读 hash，而页面内容经 `useDeferredValue` 延后提交），新增 `ShownPage` 上下文与 `useShownRoute`，返回钮跟随实际提交的页面。3 倍降速逐帧录屏核对推入、返回钮弹出、减少动态效果各 1–3 次；前端 189 项、类型检查与构建通过。真机观感仍需确认。

## 追加：底栏切换改回景深平移

用户指着样稿明确要「景深平移」。横向切换改为样稿原参数：旧页快照 460ms 缩小后退并淡出（中段 70% 时横移 16%、0.88、半透明），新页晚 70ms、520ms 从侧后方推近（中段 45% 时横移 8%、0.94、已不透明）；曲线沿用样稿（旧页 `cubic-bezier(.45,0,.2,1)`、新页 `cubic-bezier(.2,.8,.2,1)`）。只动 transform 与透明度：快照圆角改为常驻，新页比视口高，缩放原点放在视口 45% 处、不裁圆角；去掉平移视差用的压暗与新页阴影。3 倍降速录屏核对库存→在途、在途→库存两个方向。随后用户指定顶栏不动：`playTab` 抓两页顶栏的位置，各复制一份钉在 `.page-head-layer`（固定层，盖在快照与新页之上、底栏之下）原位交叉淡化，页面里真正的顶栏动画期间 `visibility:hidden`、收尾恢复；内容照样做景深平移。录屏核对两个方向与库存页滚到中段时，顶栏均停在原位。
