# 2026-10-25 · 表单封面区：状态文案缩短，按钮并排

- **作者**：Claude
- **范围**：`styles/drawer.css`（`.cover-search.is-inline`）、`forms/record/releaseCover.ts`、`useCoverSearch.ts`、`useRecordHints.ts`（状态文案）

## 出现的问题
已确认版本卡底部的封面区：状态文字（「已匹配 · 同一张专辑的封面（不一定是此版本）」）被右侧竖排的两个按钮挤成两行；来源已由封面角标说明，文案重复且偏长。

## 怎么解决的
嵌入式封面区加细线分隔；状态一句话占整行，「换一张封面」「上传封面」并排等宽（40px 高）。文案只说需要知道的：此版本自己的封面 / 借用同专辑的封面，包装可能不同 / 借用 iTunes 数字封面，包装可能不同 / 没找到封面，可以换一张或上传 / 已换成所选封面 / 已用你上传的封面 / 还没有封面。

## 验证
前端测试通过；样本库 375×812 以条码 0889854284329 以此入库，封面区一行文案 + 并排按钮，控制台无错误。

## 可能带来的新问题
无。
