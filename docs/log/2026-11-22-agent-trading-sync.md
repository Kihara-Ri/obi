# 2026-11-22 · 外部交易同步接口

## 改了什么

- 新增登记上架回执、付款订单和确认收货与到账三个入口。交易令牌单独启用，草稿令牌仍按 D-045 授权。
- 回执把闲鱼商品绑定到实物副本。付款按闲鱼订单号登记售出。两项结算事实允许分次上报，齐全时按到账日期复用现有的确认收货事务。
- 回执、订单和已收到的结算事实随账本备份恢复。保留 schema 4。新运行时模块纳入发布包校验与售卖验收触发范围。

## 出现的问题及处理

- 复现测试在实现前返回 404。补上路由、交易令牌验证和入账事务后通过。
- 界面原入口只对已经完成的收货事务拒绝重复操作。外部同步增加订单核对与幂等重试，同一对事实最多产生一次入账。手动退款时清除尚未完成的结算事实，撤销退款后按重新核对的结果处理。

## 怎么验证的

- 后端 650 项测试通过，含 7 项交易同步测试，覆盖令牌隔离、并发重试、乱序、旧单、退款及备份恢复。前端类型检查、构建和两套售卖浏览器验收通过。
- 用隔离的固定样本双 CD 随本机 HTTP 查找副本，下载四张锁定版次参考图，存草稿，再以接口文档中的示例数据沿回执、付款、收货、到账顺序跑通。只有收货事实时仍在售出中，到账后只产生一笔已交易销售单，样本净到手为 80.00 元。

## 边界

- 样本验证在临时数据目录。发布、平台订单监听和核对由外部系统负责。
- 首版由一件闲鱼商品关联一个库存副本。重复订单、不同商品的绑定冲突和已退款订单按接口契约处理。
