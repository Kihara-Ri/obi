# 2026-11-19 · 看图：顶栏关闭/页码/保存，长按改为保存面板，收回不再变方

- **作者**：Claude
- **范围**：`web/src/components/ui/Lightbox.tsx`、`LightboxBar.tsx`（新）、`PhotoLongPress.tsx`（新）、`photoSave.ts`（新）、`PhotoSave.css`（新）、`web/src/core/gallery-zoom.ts`、`web/src/styles/photos.css`、`web/src/components/icons.tsx`、`web/src/styles/tokens.css`、`web/src/App.tsx`、`web/tests/gallery-zoom.test.mjs`

## 改了什么
- 大图顶部加一行：左「关闭」、中「1 / 3」（原来在底部）、右「保存」。手机点保存交给系统分享面板（选「存储图像」进相册），电脑直接下载这一张。
- 背景从 90% 深色改成深色加模糊，背后的页面不再清楚透出来。
- 照片上关掉系统长按菜单（缩略图是链接，iOS 会弹网页预览）；改成按住约半秒弹出底部面板：照片预览 +「保存到相册」+「取消」。缩略图和大图都适用，松手不会顺带打开或关闭大图。
- 收回动画：
  - 圆角从缩略图外层取（详情照片墙的圆角在 `<a>` 上，img 自己是 0），收回最后一帧就是缩略图自己的圆角。
  - 改为等比缩放 + `clip-path` 裁切：横图收回方形缩略图时不再被压扁。

## 出现的问题
- 退出大图时先变成直角方块再变回圆角：收回终点取的是 img 的 0 圆角，且非等比缩放把横图压成方块。
- 长按缩略图打开网页预览，系统菜单里还有「打开」「添加到阅读列表」等无关项。
- 手机上大图没有明确的关闭和保存入口。

## 怎么验证的
- 单元测试：横图收回方形缩略图的帧为等比 `scale(0.24)`、左右各裁 50px、圆角换算正确。
- Playwright 手机 390 宽（触屏）注入 4:3 测试照片：长按缩略图出面板且未打开大图；取消后点按打开大图；大图里长按出面板、大图不关闭；点「关闭」收回中途为等比 + 圆角裁切，结束后卸载。
- 桌面 1280 宽：顶栏与左右翻页键正常。

## 可能带来的新问题
- 手机保存走系统分享面板，需要在面板里选「存储图像」，与原「保存实物照片」按钮一致。
- 照片上不再有系统长按菜单（拷贝等），需要时用面板保存后再操作。
