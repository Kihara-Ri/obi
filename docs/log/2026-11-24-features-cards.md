# 2026-11-24 · 介绍站「五个模块」卡片统一版式

- **作者**：Claude
- **范围**：`site/src/components/Features.astro`

## 改了什么
五张模块卡改成同一结构：图标在上，然后是名称和竖排标签。宽屏一行五列；手机两列，「整理收藏」占满首行，其余 2×2。只有「整理收藏」带「始终可用」徽标，并用稍亮的边框区分；其余四张去掉逐张的「可选」徽标，改由副标题说明：「整理收藏始终可用，其余四个按需打开；关闭只收起入口，不删任何记录。」

## 出现的问题
原版式里「整理收藏」是横排的通栏卡，下面四张是竖排卡，两种结构叠在一起；通栏卡右侧大片留白，四个「可选」徽标重复。用户反馈看着不协调。

## 怎么解决的
五张卡共用一个网格版式，宽屏（≥64rem）一行排五张。站点构建与 CSP 检查通过；本地预览 1024px 桌面与 375px 手机宽度，无横向滚动。

## 可能带来的新问题
64rem 附近每张卡约 170px 宽，标签较长时可能换行；目前标签都很短。

## 追加：承诺区文案
「成本缺失，绝不当 0 / 利润只算成本已知的部分」口号味重，用户要求换一条。改成用户认为的优势——金额能分多段、记得细、支持外币：「分毫不差 / 日元原价、运费、手续费，按当天汇率折算」，图标改成收据。目前外币只有日元（CNY / JPY），所以文案只写日元。构建与 CSP 检查通过，本地桌面预览正常。

## 追加：五张卡改成五张带腰封的 CD
- 用户觉得统一后的卡片仍缺新意。改成「架上五张日版 CD」：每张左缘一条竖排腰封（帯）写模块名，底部编号 OBI-01…05；封面区放图标和标签。和首屏封面墙左侧的黄色腰封同一意象（项目名的来历）。
- 「整理收藏」腰封常亮黄色，仍保留「始终可用」文字徽标；其余四张腰封为灰色，鼠标移上去亮起，暗示「按需打开」。减少动效时不做颜色过渡。
- 宽屏一行五张方形唱片盒（1440px 下约 205×205）；手机两列，「整理收藏」占满首行。
- 验证：构建与 CSP 检查通过；本地预览 1440px、窄窗、375px 手机，无横向滚动，悬停亮起正常。
- 可能的新问题：触屏设备没有悬停，灰腰封不会亮起，只靠副标题说明；腰封编号是装饰，不对应应用内编号。
