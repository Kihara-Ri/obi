# 2026-11-25 · 按发行介质校验黑胶规格

## 改了什么

副本保存与上架资料包共用后端介质判断，优先读发行版格式，其次查碟片格式。上架资料包沿用原有的缺省介质。

## 出了什么问题

给明确标为 CD 的样本副本提交黑胶规格后，采购评估计为 LP，上架资料包仍标为 CD。

## 怎么解决

在账本保存的统一校验中拒绝给已明确为 CD 或其他介质的副本填写黑胶规格。用固定样本验证仅提交规格时也会读取已存的发行资料，拒绝后副本和版本号保持原值。

## 可能带来的新问题

如果历史备份同时写了 CD 介质与黑胶规格，恢复时会要求先更正。未填写介质的旧副本仍可保留黑胶规格。关联 D-053、D-055。
