# 2026-10-23 · 切页快照只保留视口内内容

- **作者**：Claude
- **范围**：`hooks/usePageTransition.ts`、`CHANGELOG.md`

## 改了什么
切页淡出用的旧页快照（`cloneNode(true)` 整个 `#main`）现在克隆后立刻裁剪：视口下方（超出 40px 边距）的子树整段删掉；视口上方（已滚过）的子树清空内容、只用 `height` 保留占位；与视口相交的继续递归。滚动偏移 / 动画姿态原本按源节点序号回填到克隆，裁剪会打乱序号，所以先记下克隆节点的引用数组（`snap.els`），回填时直接用它。

## 出现的问题
库存 / 展示页封面很多时，整页克隆要复制上千个节点并重新排版、重绘，和换页渲染、底栏动画挤在同一帧，造成切页卡顿。

## 怎么解决的
快照只用来淡出 150ms，看不见的部分没必要带上。实测：400 行的长页面滚到 1200px 后切页，快照节点从 1338 降到 80，裁剪本身约 2ms，截图中快照与原页一致。

## 可能带来的新问题
裁剪只按纵向；视口内横向滚动区域仍整段保留。快照里视口外的内容不存在，若淡出期间用户拖动页面（动画期间已锁定纵向滚动）才会露出空白。仅 Playwright 验证，未真机验证。
