# 2026-11-19 · 库存工具栏：倒序并进排序，「选择」挪到顶栏

- **作者**：Claude
- **范围**：`web/src/pages/ShelfPage.tsx`、`web/src/components/PageHead.tsx`、`web/src/styles/shelf.css`、`web/src/styles/components.css`、`web/src/components/icons.tsx`

## 改了什么
- 去掉单独的 ⇅ 倒序按钮，排序下拉加一项「最早买入」：「最近买入」加上倒序，内部仍用原来的 `flip` 状态。桌面端也一样。
- 手机上的「选择」从工具栏最右端挪到顶栏左侧，和右侧的「＋」对称。
  - 点「选择」后，这个位置变成「取消」，「＋」的位置变成「全选」（由 BulkBar 顶栏接管）。
- 手机工具栏：排序下拉（原 42px）与列表/卡片（原 50px，按钮继承工具栏 42px 最小高度再加外框内边距）统一为 46px，与上一行「全部/已上架/未上架」同高；两者等分整行，左右与上方各行对齐。
- 列表/卡片的图标从 ☷ / ▦ 换成照实际布局画的线性 SVG：列表是「小方块＋两行字」两行，卡片是两列竖长卡（上封面下文字）。
- 删掉已不用的 `.flip-btn` 样式。
- `PageHead` 新增 `lead` 插槽：手机顶栏左侧的操作，只在没有返回钮的页面出现。

## 出现的问题
- ⇅ 只在「最近买入」下才生效，单看图标看不出作用，还单独占了一个 44px 方块。
- 工具栏一行要挤下倒序、排序、列表/卡片和选择四样，「选择」被挤到屏幕边，右边框被裁掉。

- 原来的 ☷（三条横线）和 ▦（密网格）跟列表的「封面＋文字」行、卡片的两列大封面都对不上。

## 怎么验证的
- 用 Playwright 在手机尺寸（390 宽、深色）下检查：
  - 顶栏是「选择｜库存/展示｜＋」，工具栏一行只剩排序和列表/卡片。
  - 选「最早买入」后月份变成 7 月在前、8 月在后；切回「最近买入」顺序恢复。
  - 点「选择」进入选择状态，顶栏显示「选择专辑」。
- 手机 390 宽与 320 宽实测：排序、列表/卡片、上一行筛选三者均 46px，左右边缘对齐。
- 新图标在手机 390 宽深色/浅色、桌面 1280 宽下截图检查，图标与文字同行居中，切换控件仍是 46px（桌面 42px）。
- 在桌面尺寸（1280 宽）下检查：没有「选择」按钮，也没有 ⇅，排序下拉正常。

## 可能带来的新问题
- 习惯点 ⇅ 的话，现在要去排序下拉里选「最早买入」。
- 选择期间，工具栏里的「全选」和「取消选择」由顶栏代替（上一条改动已经如此）。
