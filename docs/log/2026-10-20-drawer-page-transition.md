# 2026-10-20 · 抽屉内页面切换过渡（详情 → 编辑 / 发行资料 / 管理 / 返回）

- **作者**：Claude
- **范围**：`web/src/components/ui/Drawer.tsx`、`App.tsx`、`state/AppContext.ts`、`forms/DetailDrawer.tsx`、`forms/detail/ReleasePage.tsx`、`ManagePage.tsx`、`styles/drawer.css`

## 改了什么
- 抽屉里的内容切换原来是同一个抽屉直接替换内容（进入动画只在抽屉首次挂载时播），所以点「编辑」「发行资料」「管理」「返回专辑详情」都是硬切。
- 现在每次切换 `App` 递增 `drawerPage.key` 并带方向；`Drawer` 把页面（表单或正文 + 底栏）包进 `drawer-page` 容器，按 key 重挂载：前进新页从右推入（位移 32px + 淡入，`--dur-slow`），返回从左滑入；标题同步淡入。抽屉首次打开仍由抽屉自身滑入负责，不重复动画。
- 方向：`DrawerSpec.direction='back'`（二级页的「返回专辑详情」通过 `openDetail(..., 'back')` 传入）；返回手势的 popstate 恢复上一层抽屉同样按返回方向。减少动态效果时不播。

## 出现的问题
- 过渡只有 0.28 秒，模拟器截图（约 1 秒一帧）抓不到。临时把动画拉长到 4 秒逐帧验证，验证后已恢复。
- 原来的 `.drawer>form{…}` 选择器因为多了容器改为 `.drawer-page>form`。

## 怎么解决的
iPhone 模拟器：点「编辑」后中间帧可见内容右偏、按钮半透明（前进）；点「返回专辑详情」中间帧内容左偏（返回）。类型检查、构建、前端 128 项测试通过。

## 可能带来的新问题
- 只做了新页入场动画，旧页没有「滑出」，是淡入加位移的单向过渡；若要和主页面切换一样做旧页同步滑出，需要抓旧页快照（App.tsx 已有类似机制），代价更大。
- 没有处理其他抽屉之间的方向（例如艺人页 ↔ 详情的「返回专辑详情」仍按前进方向）；`direction` 字段已可用。
- 桌面右侧抽屉同样会有推入动画；主页面（库存 / 在途 / 更多等）在桌面上仍不做切换动画，这是 AGENTS.md 里的既定规则，未改。
- 未部署。

## 重做（用户选定方案并要求放慢）
- **方案**（用对比演示页选定，用户 2026-10-20 确认）：下钻页（有 `spec.back`）= 推入 + 视差；任务页（编辑、记录售出等）= 淡入上浮；返回 = 下钻的反向。要求动画整体放慢，时长集中在 `Drawer.tsx` 的 `MOTION`：推入 480ms、返回 420ms、任务页新页 340ms / 旧页 220ms（演示页是 320/280/240），曲线 `cubic-bezier(.2,.8,.3,1)`，视差 30% + 压暗 12%。
- **旧页快照**：`App.captureGhost()` 在 `openDrawer` 与返回手势恢复上一层之前克隆当前 `.drawer-page`（去掉 id、`inert`、记录滚动位置），交给 `Drawer` 的 `useLayoutEffect` 作为离场的旧页，同一容器（`.drawer-pages`，overflow 裁切）内做 WAAPI 动画，结束后移除；不重复挂载 React 组件。之前版本旧页瞬间消失、新页从透明淡入导致的空白闪烁就此消除。
- **返回箭头**：`DrawerSpec.back` 现在渲染为抽屉头部左侧的箭头；发行资料页、管理页、从艺人页进入的详情页、从详情进入的艺人页都改用它，原来底栏的「返回…」按钮已移除（艺人页底栏只留候选确认区）。
- **边缘右滑返回**：有 `back` 的页面上，左缘右滑（>70px，或 >30px 且速度足够）调用 `back.run()` 返回上一页（不跟手），一级页上仍是下拉关闭抽屉。
- 艺人页与详情之间的往返也带方向（`openArtistDrawer(..., 'back')`）。

### 验证与限制
- 把动画临时放慢 10 倍在 iPhone 模拟器里逐帧确认：推入视差（新页盖上、旧页左退压暗、箭头出现）、返回（离场页带阴影被推向右、上一页回位、箭头消失）、任务页（旧页淡出与编辑页淡入上浮叠化，无空白）、左缘右滑在二级页触发返回而非关闭抽屉。验证后已恢复正式时长。类型检查、构建、前端 128 项测试通过。
- 右滑返回不跟手（松手后才播放返回动画），真机手感未验证。
- 快照是 DOM 克隆：表单输入框里的实时值不会带进离场的旧页（只影响离场的 0.4 秒内的视觉）。
- 未部署。

## 再调（用户反馈「点击编辑的动画还是太快」）
- 任务页（编辑、记录售出等，`rise` / `sink`）：新页 340ms → 560ms，旧页 220ms → 380ms，上浮 / 下沉距离 12px / 10px → 20px（新增 `MOTION.rise`）。下钻页的推入 480ms / 返回 420ms 未动。
- 验证：类型检查、构建、前端 128 项测试通过；正常速度的 0.5 秒动画无法用模拟器截图抓帧，未逐帧复验，只改了时长与距离常量。未部署。

## 换方案：任务页「上升覆盖」（用户看对比演示页后选定，嫌淡入上浮不够明显）
- 任务页进入：新页整幅从底部升起覆盖旧页（520ms），旧页同时缩到 94%、上提 6px、四角 16px 圆角、压暗 16%；取消 / 返回：新页整幅落下（480ms），旧页回弹复位。竖向运动 = 「去办一件事」，横向推入 = 「往里看」，两类切换一眼可分。
- 代码：`Drawer.tsx` 的 `kind` 为 `push | pop | sheet | unsheet`，参数集中在 `MOTION`（含 `recede`）；新增 `.edge-top` 顶部阴影，`.drawer-page` 加 `overflow:hidden` 保证缩小时圆角生效。减少动态效果时仍是 120ms 淡入淡出。旧的 `rise` / `sink`、`riseIn` / `riseOut` 已删除。
- 验证：放慢 10 倍在 iPhone 模拟器逐帧确认进入（编辑页升起、详情缩小压暗并露出圆角）与取消（编辑页落下、详情回弹）；恢复正式时长后类型检查、构建、前端 128 项测试通过。未部署。
