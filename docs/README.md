# 治理文档索引

本目录只放三类长期文档：**规范**（决定怎么做）、**契约**（协议与边界，随代码同步更新）、**运维说明**（如何验证与操作）。
阶段性计划、实现方案与设计稿在完成或被替代后删除，历史只留在 git 历史和 [日志](log/) 中。

每份文档必须在下表登记；`tools/check_docs.py` 校验登记完整、链接有效、引用的路径与 D-/I- 编号存在。
