# 3D 附件装配与引擎归属

更新：2026-10-17；当前集成协议：Album Engine 0.3.0 / schemaVersion 2 / rigVersion 1 / modelSet `album-rig-1`。此前 0.1.9–0.1.10 的阶段边界由[已批准的完整归属方案](superpowers/specs/2026-10-15-album-engine-complete-ownership.md)替代。

## 展示与职责

九种收藏布局和平面灯箱默认 2D；打开、换张、重开都重置为 2D。宿主先核对发布结果业务有效性，再由引擎 `inspectAlbum` 检查完整实体；通过后才出现 2D/3D。点击 3D 的手势内请求感应并加载查看器、Three.js 和模型。普通封面不会加载 3D 引擎或 GLB；既有 2D 翻卡金属背面装饰保持独立。加载/装配/WebGL 失败回原 2D、提示不可用，显式重试；引擎已删除 CSS 模型和公开回退入口。校准只从编辑专辑进入，由引擎编辑器实现、宿主回调保存。

引擎拥有协议/schema、Blender 模型、素材规划/处理、生成执行、校准、装配、交互、raycast、动画、镜头、发布包及发布决策。宿主保留收藏/交易业务、发行版本明确确认、资产鉴权、灯箱导航与历史，以及 storage.py 的事务、去重、租约、并发、审计和备份。server 下旧任务/skill 路径是兼容委托；窄接口注入能力，不给引擎整个 Store 或账本数据库。

## 可携带的 canonical 文档

`AlbumDocument` 为 schemaVersion 2，包含 key/title/modelSet、assembly root/组件图及不透明 assets。组件以稳定 id、parent、mount、contains、独立 surfaces 表达包容和来源，不含账本记录、照片序号、金额、交易状态或私有 API URL。宿主通过 resolveAsset 提供授权 URL。

唯一结构来源为引擎 schema/album-document-v2.schema.json，生成的 TypeScript 声明与 Python runtime 校验共享它；src/contracts/model-set.json 是共同模型/语义槽位定义。尺寸统一毫米、角度弧度，装配入口转米；dimensions.basis 区分 template/measured 并保留来源。槽位定义局部坐标、可用容积、允许组件、开口及抽出路径，不按同名节点或整个场景包围盒猜归属。每张 CD 只能属于一个实际容器，尺寸或关系不可能时拒绝完整实体。

v1 只读兼容，确定的关系才可显式 normalize。旧附件只有种类/图片、没有唯一归属时保持 2D，不自动补归属、生成 canonical 文档、删附件或重跑模型；保留历史包和来源。历史 succeeded、包装字段或共享模型本身不是完整支持证据。

## 所有模型均经 Blender 制作

包装、托盘、口袋、CD、OBI、歌词本、内袋都在独立引擎用 Blender 制作并真实导出 GLB。可复现源包括 tools/model-library/build_library.py 和 build_accessories.py。原 21 个共享模型加 component-obi.glb、component-booklet.glb、component-inner-sleeve.glb、component-foldout.glb 一起发布。运行时加载已制作模板，设置其形状键、节点尺度、材质和装配变换，不用 Three.js 另建附件网格。

OBI 为连接的前面–书脊–背面纸片，连续 UV 只使用本侧标独立素材；case_depth/band_width/height 是 Blender 已制作形状键，纸厚保持独立。普通歌词本是独立印刷面与中性纸块；明确 fold 声明的2–6联折页使用 Blender 铰链，双面各自完整映射长图，不虚构缺少的印刷面或装订页。内袋有独立前后纸层、三条封边和单侧开口，反向开口移动封边而非镜像印刷。缺少任何独立印刷图时保留示意，不借主封补图。nominal 模型边界是标准模板，不代表实物已测量。

## 装配与交互

- OBI 依本外壳印刷边界/厚度装配，展开前先撤离折轴。
- 歌词本挂入声明的活动纸页槽/口袋；内袋挂入其声明 pocket 并包住指定 CD，不共用固定偏移。
- 纸件只有可达且可见的边缘才参与抓取；内袋充分退出后才能从该袋开口取 CD。
- 关闭先收 CD 和内部纸件，再合纸页；反向操作从当前位置接管。模型、遮挡、raycast、动作路径和镜头共用同一装配结果。
- 宿主响应关闭/不可用事件；灯箱导航、历史及浏览位置不交给引擎业务层。

## 分发与验证

引擎作为可选官方 ZIP 安装，在设置中真实安装或卸载。宿主未安装也能启动，保留实体、贴图、固定 GLB 与专辑镜头参数；重装即可使用。所有 3D 修改回到引擎项目。纯数据校验导出与插件入口、模型固定及备份边界见[插件契约](AlbumEngine插件.md)。

验收数据唯一源为 tools/seed_samples.py；先扩充样本及 tests/test_sample_library.py，再导出引擎 fixtures。OBI、歌词本、内袋用各自合成 PNG，不能一张封面充作三个实物。验收需覆盖三个代表样本、125/135 mm Gatefold 完整组合、左右归属/内外开口、实测缩放、双 CD、缺图、非法尺寸/关系及取放中间位置；宿主覆盖默认 2D/显式 3D、权限时机、失败返回及清理。自动/浏览器检查不能替代真实模型质量、实际发行版测量、手机感应或实机帧率。本文说明当前契约及验收要求，不声明最终全套验证或部署已完成。

## 保留的历史根因

0.1.x 曾把 OBI 高度固定 133 mm，套在 125 mm 纸板上；还依首个 Pocket 节点和固定偏移挂纸件。后续基于 GLB 边界的局部修正证明问题来自尺寸与归属缺少统一契约；这些 GLB 边界是模板几何，并非“真实实物测量”。0.2 将其收口为引擎文档、槽位和 Blender 模板装配，不能把单例修正当全部组合或当前最终验收已通过。
