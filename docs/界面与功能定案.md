> 从 [AGENTS.md](../AGENTS.md) 原样移出（2026-11-03，D-039），内容未改。这里每一条都是用户确认过的定案：改动对应领域前先读对应小节，与之冲突的改动须先问用户。


## 功能组合

- 基础收藏始终可用；`showcase`（收藏展示）、`acquisition`（购入记录）、`trading`（二手交易）、`circulation`（海外周转）按服务端 `modules-v1` 设置启用。海外周转依赖购入记录，展示与交易可独立启用。旧三键配置缺少展示开关时按关闭读取，不自动回写。
- 「整理收藏」与「展示收藏」是可选组合，完整管理入口始终保留。用户可调整默认首页（服务端 `start-page-v1`，收藏管理 / 收藏展示）；显式页面链接优先。关闭展示时进入管理，保留首页偏好，重启用后恢复。手机展示入口：按上条由默认首页决定（2026-10-17 起不再放在「更多」）。中文名称变更保持 `showcase`、`gallery` 路由和已有偏好键兼容。
- 收藏展示以手机触屏为主要场景，沿用独立实物副本；国内、海外、在途全部展示，上架但未成交仍属于收藏，售出中/已售出/回收站不展示，不提供在途开关。九种布局共用范围、搜索、排序与浏览位置，展示偏好单独保存在浏览器，不改库存视图。
- 扇形交接沿原弧线就地转侧并小幅横向让位，不能附加逐张上下跳或缩放脉冲；换层时可见盒体轮廓分离或被更前方封面完全遮挡，不能在可见重叠处跳切 z-index。交接随拖动进度连续可逆；快速同向点击立即累计目标，不逐张排队播放，反向或重新拖动从画面当前位置接管。胶片用原生横向连续滚动，可停在任意位置。翻阅/唱片箱/扇形展开/环形展架在按住拖动期间持续沿各自轨道跟手移动，松手后以更强吸附迅速对齐中心；唱片箱普通一次划动约翻一张，长距离拖动仍可持续翻找，沿竖向翻动，封面不透明地按深度叠放，侧壁、前挡板与箱底裁剪共同遮挡，不能用悬空横杠代替箱体。桌面铺开连续向下铺满全部结果；等距封面墙沿左上↔右下斜向轨道无限循环移动、任意停留，只渲染视口附近封面。桌面与等距布局不分组、不分页。轨道内单指拖动由轨道处理，轨道外保留页面滚动；多指缩放、屏幕边缘返回、指针取消与减少动态效果均须保留，拖动不得误触放大。触屏验收须检查按住时的中间位置与松手后行为，浏览器测试不等于实机帧率证据。
- 展示范围可选全部、本地艺人或自定义手动组；艺人按本地名称精确筛选，搜索在所选范围内继续收窄。组成员是有序的独立副本 ID，可跨组重复；支持改名、添加/移除、调整顺序和删除组。选择组默认使用组内顺序，可改用普通排序。组经服务端事务保存并随备份恢复；模块关闭或成员售出/进入回收站时保留成员关系，仅过滤展示。组写入、并发冲突与恢复契约见 [模块扩展指南](模块扩展指南.md#收藏展示与手动组)。
- 展示页工具区两行（2026-10-26 重排）：第一行「范围 · 数量」按钮 + 搜索；第二行布局名按钮｜齿轮图标（展示设置）｜巡游开关 + 速度胶囊。范围 / 布局按钮打开抽屉，不加小字标签、不加向下箭头；模式按钮只显示当前布局名，保留「展示方式」无障碍名称，点击打开三列布局预览抽屉（缩略图用当前范围的真实封面，布局描述只作悬停提示）。「展示设置」每项一行（左标题、右 `Seg` 分段控件）：顺序、封面大小、间距、滑动方向、显示标题与艺术家；不放巡游速度。九种布局均支持巡游；巡游开关（播放 / 暂停图标）始终在工具区，开启后旁边出现速度胶囊（显示倍率如「1×」），点开就地浮出 5 档分段：很慢 0.5× / 慢 0.75× / 标准 1× / 快 1.5× / 很快 2×，选中即生效、浮层不关，点外面或 Esc 收起；关闭巡游隐藏胶囊并保留档位。档位所有布局共用，保存为浏览器偏好 `roamingPace`；旧的按布局秒数 `roamingSpeeds` 只在没有档位时用当前布局那一项换算到最接近的档位，不再写回。各布局秒数 = 默认秒数 ÷ 倍率（`galleryRoamingSeconds`）：翻阅/唱片箱/扇形展开/环形展架先停留，再按正常速度切换一张，秒数只控制停留；封面墙、瀑布流、胶片、桌面铺开按秒/张连续滚动；等距封面墙按秒/排（每排三张）连续滚动。标准档秒数：封面墙 8、瀑布流 10、胶片 6、翻阅 4、唱片箱 5、桌面铺开 10、扇形展开 4、等距封面墙 4、环形展架 4。沉浸展示的右上角悬浮条为「巡游开关 + 速度胶囊｜退出沉浸」，与工具区同一组控件，静止 3 秒淡出、触摸再现；进入沉浸不改变巡游开关。巡游默认关闭且不保存为启动状态，开启后只由用户显式关闭；收起展示设置、改范围/顺序/大小与切换布局均保留开关状态。起停是短过渡而不是长加速（2026-10-27）：连续布局 0.5 秒三次缓出到设定速度、0.35 秒缓停（`rampEase`，不用 S 形曲线——它前半段几乎不动）；中心布局点开巡游约 0.6 秒后翻第一张，之后按停留时间。连续布局写滚动统一走 `paintGalleryScroll`：WebKit 把 scrollTop/scrollLeft 取整，慢速巡游会停几帧跳 1px（颗粒感），所以滚动只写整数、不足 1px 的余数用滚动容器自身的 `translate` 补，触碰 / 滚轮 / 停下时清掉；巡游帧里不得读布局（行距等在尺寸变化时量好缓存）。触碰/拖动或手动浏览时暂时避让，打开灯箱、抽屉及后台期间暂停。四种中心布局在操作结束、关闭灯箱或抽屉、返回前台后重新按设定间隔计时；连续布局在操作结束约 3 秒后继续，关闭灯箱或抽屉、返回前台后自动恢复。减少动态效果暂停自动运动但保留开启意图，恢复后继续。各布局外观（2026-10-27 逐个确认）：封面墙、瀑布流、桌面铺开始终是铺满工具区与底栏之间的滚动窗口，瀑布流封面按副本稳定错落大小，桌面铺开是木纹桌面上随手散放（±8° 与错位、偶尔压角）；封面加载时显示柔和微光再淡入；胶片约 80% 屏宽、无外框，箭头为轻量一行；翻阅缩小中心、两侧各露两张并带地面倒影；唱片箱为实木箱、前挡板加高（当前封面露约 70%）、翻过的唱片向前倒下淡出；扇形展开中心与紧邻一张保持原弧线（换层时轮廓已错开），外侧收紧，手机上两侧各露两张；等距封面墙四边渐隐、当前封面抬起并显示序号；环形展架中心约 42% 宽、环半径收紧、整块椭圆底座、转到后面的封面变暗。巡游循环：封面墙 / 瀑布流 / 桌面铺开 / 胶片巡游时无缝循环（重复渲染整周期副本，关掉巡游回到单份范围后撤掉副本）；四种中心布局只在巡游时首尾相接（槽位折回记录序号），手动浏览仍停在两端；等距封面墙一直循环。翻阅与环形的关键帧由 `web/scripts/gallery-orbit-keyframes.mjs`（输出 `components/GalleryOrbit.css`）、扇形由 `gallery-fan.mjs` 按 `core/gallery-motion.ts` 的姿态模型在 prebuild 生成，改姿态不要手改 CSS。轨道布局的辅助箭头与位置指示放在封面舞台内，合成底部居中的一颗半透明胶囊「‹ 序号 ›」（2026-10-27，不再是两角各一个大圆钮），箭头触控区域至少 44×44px；胶片下方不用滑杆，改为印样条（一排小封面，当前高亮居中，点哪张跳哪张）+ 同款胶囊；舞台下方不显示摘要、操作栏或手势提示。封面墙与瀑布流保留逐项文字。中心布局点击邻张先选中，点击当前封面（总览/胶片中为任意封面）打开默认 2D 的全屏灯箱。
- 展示布局中的专辑统一为平面封面；灯箱每次打开、换张、重开均默认 2D，仅当前有效发布实体通过引擎能力检查后才显示 `2D / 3D` 分段切换。不能仅凭包装字段、共享 GLB 或历史成功任务自动进入 3D。点击 3D 的同一手势内才请求感应、加载查看器/Three.js/模型；2D 不创建 WebGL、不下载 GLB、不申请感应。切回、换张、关闭清理资源；模型/装配/WebGL 失败回到 2D 并提示“3D 暂不可用”，可显式重试，引擎不保留 CSS 模型或其公开入口。背景、Esc、浏览器返回关闭并恢复位置。包装采用 Jewel Case、Card Sleeve、Gatefold Sleeve / Digisleeve、Digipak、Digibook、Rigid Box，Mini LP/Slipcase 为独立属性；独立盒盖、固定齿纹托盘、真实轴销、口袋与连续纸脊结构保留。单口 Card Sleeve 不翻页，2CD 不自动加厚，紙ジャケット不自动认作 Mini LP 单口套；Uncoated/Matte/Gloss、旧文字及缺图示意语义保留，含糊结构由用户确认，贴图只引用本副本照片。后台/减少动态效果暂停，实机感应及帧率须独立验收；所有包装与 OBI/歌词本/内袋/CD 模型均在独立 Album Engine 用 Blender 制作并导出 GLB，运行时只加载模板并设置已制作的形状键、节点尺度、材质与装配变换。模板 nominal 尺寸不宣称实测。数字实体的状态、附件补充与盘面校准入口在展示灯箱的「实体设置」（D-015：数字实体属于收藏展示，不放在编辑表单或管理页），展示只显示封面/包装与标题；协议、归属和验收见[包装结构与模型贴图](模块扩展指南.md#包装结构与模型贴图)。
- 逐张序号只用于四种中心焦点布局；胶片、等距墙等无单张焦点布局仅保留总量与连续浏览进度。胶片的滑杆与辅助箭头组成统一导航带，隐藏重复的原生滚动条外观但保留原生滚动。浏览布局仅呈现平面封面，悬停抬起（仅鼠标 / 键盘，手指触碰不抬起，2026-10-24）叠加在内层，不覆盖轨道姿态；等距墙与中心舞台按工具区和底栏之间的剩余空间伸展，保留触控与封面边界。

## 界面规则

- 手机底栏为「库存 / 在途 / 售出中 / 更多」，按模块隐藏无关入口。**展示的位置取决于用户的默认首页**（设置 · 打开应用时进入）：首页是收藏展示（以展示为主）→「展示」是底栏第一个标签；首页是收藏管理（以管理为主）→ 展示不占标签，库存页与展示页手机顶栏中间是「库存｜展示」分段切换（`ShowcaseSwitch`，此时库存标签在两页都高亮）；国内/海外在库存页内切换，切换时保留排序与上架筛选。「更多」是独立页面，只放账本、交易记录、设置与备份、外观、安装；它的子页在手机顶栏左侧带返回钮（回收站回到设置）。手机所有页面共用一行式顶栏：返回｜居中标题｜操作（次要为文字钮、主要为圆形强调钮），见 `PageHead` 与 `styles/layout.css`。不再使用更多弹出面板。账本页由原「账本概览」与「收支统计」合并而成，旧链接 `#ledger` 会跳到账本。
- **管理只管钱，编辑只管元数据（2026-10-21）**：买入金额、币种、日期、额外费用、购买渠道在专辑详情 → 管理 → 「编辑买入信息」（`forms/PurchaseForm.tsx`）；「编辑专辑」不含这些字段，仅新增专辑时填写。「调回海外」成功后 toast 带「撤销」（bulk `undo_to_overseas`，按审计还原包裹关联与上架标记，之后有变动则拒绝）。管理页「流转」用分段控件在海外 / 国内库存间手动切换（`forms/detail/FlowSection.tsx`；bulk `to_domestic` 只允许从海外库存，不动运费分摊；`undo_to_domestic` 同样按审计 + revision 校验）；在途 / 售出中 / 已售出不给手动改，避免与包裹、交易的账对不上。
- **相机扫码（2026-10-21）**：`components/BarcodeScanner` + `core/barcode-detector.ts`；前端依赖新增 `barcode-detector`（zxing-wasm 垫片，wasm 作为本站静态资源，CSP 不放行外部域名）；只识别 EAN-13/8、UPC-A/E 并要求 GS1 校验位通过。相机需要 HTTPS，失败时给出原因并保留手动输入。
- **抽屉左缘手势（2026-10-21）**：手机抽屉只能向下收回，空间结构不得被横推破坏。左缘 28px 内起手在 `touchstart` 就 `preventDefault`，拦掉 iOS 系统「边缘返回」整页滑动（只在 touchmove 拦会和跟手叠在一起）；一级页右滑 = 映射为 sheet 下拉；二级页右滑 = 只动标题线以下的页面层跟手右移、下层视差露出，松手后 pop 动画从手指位置接着播（`popFromRef`），标题栏不动。下拉时遮罩（模糊+压暗）随位移淡出（`--scrim-o`）。
- **软键盘（手机抽屉）**：页面不为键盘滚动 / 追赶。**手机抽屉里的文字输入一律走聚焦输入层（2026-10-28 用户定案）**：点输入框时原框不拿焦点、不弹键盘，在键盘正上方升起 `FocusInput`（portal 到 body，背后页面不动），输入实时写回原框，「取消」/ 遮罩 / Esc 还原，单行回车会转发给原框。由 `Drawer` 内的 `useFloatingFields` 统一接管，表单不用逐个改；只读 / 禁用、勾选 / 单选 / 文件 / 日期等非文字类型、已自带浮层的框（金额、专辑名 / 艺人、发行版查询）不接管，个别框需原生输入时加 `data-native-input`。抽屉自身不做任何键盘避让（不平移、不按键盘滚动、不补键盘余量）：旧的 `translateY(visualViewport.offsetTop)` 补偿会抵消 WebKit 露出输入框的平移，把输入框压回键盘下。代价：不能用键盘 ▲▼ 在字段间跳。iOS 键盘顶部的 ▲▼ ✓ 条是系统控件，网页无法去掉。
- 设置 · 功能少字、图标化（2026-10-21）：顶部使用方式图标卡 → 功能图标开关与默认首页 → 迷你手机实时预览（底栏与详情管理，新增 / 收起有角标），完整变化清单与说明收在「全部变化与说明」；预览数据 `core/modules.ts` 的 `SURFACE_GROUPS` 须与导航及各表单的模块判断保持一致；设置 · 数据按备份 / 恢复 / 导入导出 / 回收站分块。

## 售卖草稿（2026-10-28 更新，D-031）

- 启用 trading 后，一键沿用已有发行资料，自动完成实物核对及 AI 文案写作；不重新查询发行版，不逐项要求人工确认。无照片允许生成，未知品相在内部保持「尚未核实」，但不写进买家可见文案（见下条闲鱼约定）；仅照片观察须附真实照片编号。明确版本冲突突出提示，争议信息不写入文案。不得凭照片承诺播放、读取、真伪、首版、附件齐全或无瑕疵。
- 默认“简洁直售”，另有“收藏交流”“详细说明”及一套“我的风格”（选项式配置：语气 / 篇幅 / 排版 / 标题 / 曲目与品相开关 / 固定结尾 / 其他要求，由前端拼成 instructions，选项值随风格保存仅作回显；旧的自由文本风格仍可选）。默认风格与自定义预设经 storage.py 事务写库、带 revision 并随备份恢复。风格不覆盖事实；用户本次补充是明确声明，历史私人备注不默认发送。
- 分析与文案分两次推理；换风格复用有效分析，照片、发行资料或本次补充变化则重新核对。空白草稿成功后自动保存；已有标题/正文与本次手动编辑先展示候选，显式采用后才覆盖。重新分析不改写原稿；照片或资料改变保留旧正文、旧证据失效。任务与保存均校验 revision，保存只经 storage.py。
- **闲鱼文案约定（2026-10-29，用户确认）**：闲鱼发布页只有一个描述框、没有单独标题，标题即描述第一行，「复制文案」= 标题 + 空行 + 正文。标题不含书名号 / 括号 / 引号 / 表情（易被截断或省略，服务端 `listing_copy_clean.clean_title` 兜底）。买家可见文案不得出现不确定措辞：内部「尚未核实」标记与待核实 / 冲突清单不交给写作模型（只传 `versionConflict` 布尔值），品相未知则整段不写；写作后若含“不确定 / 未核实 / 需看实物…”先让模型重写一次，仍有则整句删除（`hedge_hits` / `strip_hedges`）。不标成色等级，品相用具体克制的日常用语（如“盒面有轻微使用痕迹”），禁用全新 / 99新 / 完美 / 无瑕等。第一张照片是闲鱼首图、影响列表展示：上架页可「设首图」，顺序保存在草稿 `photoOrder`，「保存图片」与 ZIP 按该顺序（照片仍是全部，不是选图）；重新生成沿用已设顺序。
