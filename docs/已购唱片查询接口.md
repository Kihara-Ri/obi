# 已购唱片查询接口

Obi 服务器可向经授权的客户端提供已购唱片检索。接口使用标准 HTTPS 和 Bearer 令牌，返回副本状态与发行资料。

## 开通和撤销

由实例管理员给调用方签发一枚带 `collection:read` 权限的令牌（见[对外令牌](对外令牌.md)），立即生效，不用重启：

```sh
docker compose exec app python3 -m server.client_admin add 查一下有没有 --scope collection:read
```

令牌只打印这一次，用密钥管理器或可信的加密通道交给调用方；`rotate` 轮换、`revoke` 撤销，都立即生效。旧方式 `credentials/collection-read.token`（`obi_collection_` 前缀，`0600`，重启后生效）仍按 `collection:read` 识别，可用 `import-legacy` 迁移。

`collection:read` 只适用于本页的 GET 路由，不返回金额。需要成本与利润汇总时用[采购评估](采购评估接口.md)的 `insight:read`。开通查询无需开启「购入记录」或「二手交易」模块。浏览器和安卓本机模式不提供此远程接口。

## 请求

`GET /api/collection/purchases`。请求头为 `Authorization: Bearer <令牌>`。

| 参数 | 含义 |
| --- | --- |
| `q` | 必填，1–200 字。仅在本实例的账本中查找。 |
| `by` | `text`（默认）按艺人或专辑名查找，忽略大小写，空格分隔的各项都要匹配。`catalogNumber` 或 `barcode` 按归一化后的编号精确匹配。 |
| `status` | 可选，取下表中的一个副本状态。省略时覆盖全部状态。 |
| `offset` | 从 0 开始的非负整数，默认为 0。续页传上一页的 `nextOffset`，其余参数保持相同。 |

客户端可将令牌放在自己可读的 `0600` 文件中。下面以目录编号检索，令牌经标准输入传给 curl。

```sh
OBI_COLLECTION_TOKEN_FILE=/path/to/obi-collection.token
(
  set +x
  token=$(cat "$OBI_COLLECTION_TOKEN_FILE") || exit 1
  printf 'Authorization: Bearer %s\n' "$token"
) | curl -q --silent --show-error --fail-with-body --max-time 15 --get --header @- \
  --data-urlencode 'by=catalogNumber' --data-urlencode 'q=UICE-0003' \
  'https://your.domain/api/collection/purchases'
```

按艺人或专辑查找时，去掉 `by` 并把 `q` 换成名称，如 `q=King Crimson` 或 `q=叶惠美`。

## 响应

200 返回 JSON，每页最多 20 个实物副本，按艺人和专辑名排列。同名专辑的多个副本各占一项。`nextOffset` 为 `null` 表示没有下一页。响应带 `Cache-Control: no-store`。

```json
{
  "copies": [
    {
      "artist": "King Crimson",
      "title": "Red",
      "status": "held",
      "format": "CD",
      "catalogNumber": "UICE-0003",
      "barcode": "2001000000036",
      "country": "JP",
      "edition": null,
      "version": "Mini LP Sleeve",
      "pressing": "日版",
      "obi": "带侧标"
    }
  ],
  "nextOffset": null
}
```

| `status` | 含义 |
| --- | --- |
| `held` | 仍在国内或海外库存，包含尚未成交的上架副本。 |
| `in_transit` | 已购买，入库运输在途。 |
| `sale_pending` | Obi 副本状态为售出中，尚未标记已售。 |
| `resold` | 已售出。 |
| `removed` | 仍有购买证据但已放入回收站。 |

返回的每一项都有正数买入金额或实际人民币支出。表单可以预填日期和渠道，仅有这些字段、费用或售出记录时无法确认曾购。空结果表示未匹配到可确认的买入记录。

发行资料缺失时相应字段为 `null`。`format` 优先取已保存的发行介质名称，缺少时取各碟的介质名称。`version` 是副本的碟盒或包装名称，`edition` 是发行版说明，`pressing` 和 `obi` 沿用副本记录。`country` 是发行地区。按名称取得的候选可再用编号、条码和介质核对版本。判断重复买入时检查 `held` 和 `in_transit`，其余状态可用于回顾购买历史。

响应只含上述字段。采购及成交金额、渠道、账户、订单、买卖双方、运输明细、备注、照片和内部记录 ID 均不在响应中。

未开通返回 404。开通后凭据缺失或错误返回 401，带 `WWW-Authenticate: Bearer`。参数不符合约定返回 400。错误响应为包含 `error` 的 JSON。

## 固定样本验证

在仓库根执行 `python3 tools/run_tests.py test_collection_api`。独立 HTTP 客户端使用临时账本和固定样本验证查询、字段边界、状态、分页、停用与令牌隔离。
