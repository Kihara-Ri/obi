# 专辑数字孪生自动化方案

网站已接入**手动触发的 skill agent 生成管线**；新增专辑仍先显示 2D，不会自动开始生成。点击后，服务端按具体 CD 发行版获取素材，调用配置的视觉模型规划并校准，校验成功才发布数字实体。`server/skills/album-digital-twin/` 是随应用打包的技能源；本次 *Lift Your Skinny Fists* 的流程联调使用模拟视觉模型，实物贴图沿用已确认的区域，不能证明真实模型对任意专辑的校准精度。

## 采用哪条路线

建议采用**参数化包装模板 + 精确发行版本识别 + 实物采集**。常见包装复用 Blender 模板，自动填写结构、尺寸、材质和各面贴图，不必逐张重做模型。印刷图与开合轴、纸袋、托盘分别处理，方便保持结构正确。

不以单封面生成未知背面。网上同版图能补通用印刷，但这张副本的折损、旧化和附件必须从实物采集。没有测量的模型仍是参考比例。

也不将整件摄影测量扫描作为主路径。Apple 指出透明、高反光、很薄的结构和拍摄时变形的物体容易导致低质量或失败；CD、透明盒和可展开纸套正涉及这些条件。因此模板路线更适合这里的可开合包装，这是依据采集限制作出的工程选择。[Apple 采集指南](https://developer.apple.com/documentation/realitykit/capturing-photographs-for-realitykit-object-capture)

## 最少采集什么

- 正面、背面、完整展开内页、书脊及袋口/连接处；每张取出 CD 的盘面。清晰的一张图可以覆盖多个面。
- 清晰条码、唱片编号；版本仍冲突时补内圈刻码。不凭标题决定包装。
- 要求实物尺寸时，提供宽、高、厚度，或同平面的尺子与厚度侧照；避免强反光和硬阴影。

视觉模型自动判断结构、碟数、开口方向、照片角色和每块印刷面的四角坐标；只对低置信度、互相矛盾或校准失败的项要求确认或补拍。没有拍到的面保留“缺失”，不复制封面填满。当前还需开发四点校准界面。

发行版先用条码/编号查询，再核对艺人、碟数及可见结构。MusicBrainz 支持 `barcode`、`catno` 搜索；确认具体 release 后，CAA 可列出原图、缩略图、角色与审核状态，角色包含 Back、Panel、Booklet、Medium、Spine。但图集可能不完整，角色也不等于已裁好的一张模型贴图。[版本查询](https://musicbrainz.org/doc/MusicBrainz_API/Search)、[CAA API](https://musicbrainz.org/doc/Cover_Art_Archive/API)、[图片角色](https://musicbrainz.org/doc/Cover_Art/Types)

## 现有基础与缺口

`server/digital_twins.py` 使用独立的两阶段 skill agent，复用 `VisionService.agent_json()` 的配置与并行槽位；返回结构化包装和逐面四角坐标，文件及结果经 `storage.py` 发布。普通录入识别与批量草稿仍使用原合同，不会因新增记录自动调用生成 agent。

`PackagingEditor.tsx` 保留副本的人工结构和照片绑定；生成不会改写它们。`core/digital-twins.ts` 将已发布实体映射为仅供查看的模型参数，`album-model-assets.ts` 选择共享 GLB，投影模块绑定原图，`album-scene.ts` 渲染。多面素材由独立生成任务获取，普通 `covers.py` 仍主要补正面。

分辨率也有限制：`web/src/core/photos.ts` 上传压成长边 1600 的 JPEG；`album-scene.ts` 将 GPU 贴图限制为长边 1024（舞台宽度小于 600）或 1536。要放大检查小字、纸纹，需保留高分辨率原件并另做预览；当前不能称保留相机原始像素。

## 三阶段落地

1. **自动建草稿**：把识别结果接到 `packaging.photos/photoRegions`，加入补拍与校准；证据充分的普通模板自动生成，人工已确认字段受保护。
2. **按版补图与批量保存**：接通已确认 release 的多面图集，扩展现有导入草稿；每面记录本副本照片/同版参考、来源、确认状态和缺失原因，全部写入经 `storage.py`。
3. **提高实物精度**：保留高分辨率原件，加入测量与特殊结构模板；检查接缝、穿模和开合中间态，再做手机实机质量验收。

服务端继续使用标准库调用已配置模型；Blender 留在模板制作工具链。目标是资料充分时自动复现、资料不足时明确指出缺口。
