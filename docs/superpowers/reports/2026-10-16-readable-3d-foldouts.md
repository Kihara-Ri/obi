## 已实施

- 引擎 Blender `component-foldout.glb`、可选 `booklet.fold` 协议、Python/TypeScript 装配与发布回读、两面完整 UV 和折页运动已存在并通过结构验证；其他普通 booklet 不自动识别为折页。
- 初始镜头按关闭的封面、窗口像素而不是内容物活动半径取景；CD/侧标/内页有各自的旋转目标，Q/E 进行独立 Roll；折页以 F 或双击展开和折起。
- 修复检查器按方向键时在 RAF 动画排队状态下未及时显示新姿态：键盘路径改为 `move(true)`，直接输入路径即时 `scene.paint`，不再等待下一帧绘制。
- 共享元素封面缩放的浏览器验收改成在 `pointerdown` 捕获当时实际缩略图像素，避免 Playwright 点击前微小二次自动滚动产生错误失败。
- macOS 浏览器验收使用硬件 Metal ANGLE；SwiftShader 在固定样本和软件光栅下持续占用多个 CPU 核心并阻塞 requestAnimationFrame，不足以代表用户设备正常硬件加速体验；非 macOS 保留软件兼容后端。
- 本地封装 `@diedu/album-engine@0.2.2`、导出 Python runtime，宿主通过锁定 tgz 引用构建；更新 tgz 后同步更新 lockfile integrity 再运行 `npm ci`，以免同版本缓存继续复用旧源码。
- 固定样本离线发布 21 张真实封面、16 个画廊项、3 个真实图集模型；Lift 四联（正反两面来自独立来源），Illinois 六联（无可靠背面，不复制、不虚构）。固定开发数据版本 `2026-10-16.3`；原 0.2.1 素材和完整账本备份留在用户开发目录 backups，正式 `data/` 未修改。
