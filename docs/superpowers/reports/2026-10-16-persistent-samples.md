# 固定样本持久化与测试整理验收

日期：2026-10-16；样本版本 `2026-10-16.2`；Album Engine `0.2.1`（本地集成，未发布）。

## 交付

- `tools/preview_samples.py` 为统一入口；仓库外固定目录保留同一实例，正常启动离线校验后运行。基础业务 seed 仍复用原 21 副本定义。
- `tools/sample-bundle.json` 锁定公开来源、38 个去重文件、21 张副本封面、三个 CD 版次参考文档及模型/引擎契约。二进制素材不入 Git。16 张属于展示范围。
- `tools/sample_bundle.py` 在启动前验证文件内容、完整发布资产与每个印刷面绑定；相同资产集但交换正背面的文档也不能通过。
- `backup/restore` 使用 Store 的完整 JSON 事务与去重图片包；在没有原缓存且禁止联网的空目录成功恢复。更新先归档旧实例，素材包与新实例一起暂存，失败保留旧状态，成功才切换。
- Apple CDN 的 JPEG EXIF UserComment 会变化：实测图像编码/解码像素相同，仅注释内容变化。只归一化该字段，保留 JPEG 像素、方向与色彩；不接受其它内容变化。CAA / Discogs 原件逐字节保留。

## 真实缺图根因

除先前的临时目录/未持久化资源链外，本次浏览器门槛还发现 Illinois 的 `insideRight` 虽已发布，Jewel GLB 没有相应印刷材质，因而渲染器根本不会请求该图。已在引擎的 Blender 构建器为固定背卡正面增加 `Print_insideRight`，重建四个 Jewel 模板；黑托盘继续遮挡，透明托盘可显示，几何尺寸及机构不变。新增 GLB 结构回归先复现遗漏，再验证修复。

- 宿主 21 项纯引擎测试迁入引擎 Python 测试，宿主留三个兼容 smoke test；引擎 CI 增加 Python 执行，业务授权、金额、并发、备份覆盖保留。

- 19 种模型几何、合成光栅、运动/装配和业务边界测试继续保留；它们与真实图验收覆盖不同的风险。
