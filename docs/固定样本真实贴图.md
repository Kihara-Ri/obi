# 固定样本的真实封面与 3D 参考图集

日常展示验收使用同一份 21 副本样本库：全部副本有真实作品封面，其中收藏展示显示 16 张；三个明确 CD 版次有真实图集参考模型。封面、版次映射和发布资产通过内容哈希固定，正常启动不联网补图。

```sh
# 首次获取公开来源；后续不需要重复执行
python3 tools/preview_samples.py prepare --download
# 每次继续开发，启动同一个实例，默认端口 63282
python3 tools/preview_samples.py
# 校验图片、印刷面绑定、引擎版本，并输出浏览器验收清单
python3 tools/preview_samples.py check > /tmp/obi-check.json
npm --prefix web run test:browser -- --url http://127.0.0.1:63282 --expectations /tmp/obi-check.json
```

浏览器 CLI 首次需在 `web/` 执行 `npx playwright install chromium`。日常开发目录在 macOS 为 `~/Library/Application Support/Obi/development`，Linux 为 `$XDG_DATA_HOME/obi/development`（未设置时用 `~/.local/share`）。`OBI_DEV_HOME` 或 `--home` 可指定独立验收目录；生产 `data/` 被拒绝。不要每轮另起临时库后只运行基础 seed。

目录包含 `bundle/`（去重原图与锁定清单）、`instance/`（账本与发布资源）、`backups/`（显式重建前归档）。正常启动保留副本 ID 与任务，不重新抓图或生成。版本变化、文件丢失、损坏或错误的印刷面绑定都会阻止启动；运行中的实例使用独占锁，修改前先停止服务。

仓库只跟踪 `tools/sample-bundle.json` 中公开来源、SHA-256、固定版次声明和引擎/模型契约；约 89 MiB 的二进制素材位于开发目录。首轮获取拒绝来源内容变化，不接收相似图片。Apple CDN 会改 JPEG 的 EXIF UserComment；初始化仅将该字段清零，不解码或重编码，像素、方向和色彩配置保持原样。CAA / Discogs 图不修改字节。

```sh
# 有素材包后，新目录可完全离线构建
python3 tools/preview_samples.py prepare
# 版本升级或显式重新生成：先完整归档旧版本，再导入当前版本
python3 tools/preview_samples.py prepare --download --rebuild
# 停止预览后，完整备份；包含账本、图片、已发布资产和离线素材包
python3 tools/preview_samples.py backup --file /tmp/obi-preview.tar.gz
# 在空目录恢复，既不依赖旧缓存，也不联网
python3 tools/preview_samples.py restore --home /tmp/obi-restored --file /tmp/obi-preview.tar.gz
```

备份只适用于固定开发样本，不替代生产数据备份。旧版本快照需与其对应代码和锁定清单恢复；当前版本不会静默接收旧契约。损坏快照在暂存目录失败，不留半个实例。JSON 账本备份本身不含图片，不能单独承担贴图恢复。

扩充样本时先修改 `tools/seed_samples.py` / `tools/sample_reference_models.py`，核实公开版次图集，增加 `tests/test_sample_library.py` 覆盖。维护者可调用 `tools.sample_bundle.capture(data_dir, reference_cache, new_bundle)` 冻结已准备的固定库；更新 sampleVersion 后检查来源、全量哈希、引擎契约及真实浏览器，不只改清单中的版本号。引擎包、runtime 或 GLB 更新也要重新冻结契约。

参考模型选取下列公开 CD 发行版，仅用于演示，不证明收藏实物属于该版本。

| 样本 | 发行版 | 模型与已映射素材 |
| --- | --- | --- |
| Lift Yr. Skinny Fists… | [日本 PCD-5608/9](https://musicbrainz.org/release/e51e1f8b-62ba-388f-8567-0c051b575351) | 双袋 Gatefold；正背、内封左右、书脊、CD 1 / 2、侧标、折页首页 |
| Loveless | [CRECD 060](https://musicbrainz.org/release/cd32c6cf-f979-39e7-a4ec-157d3a560d06) | Jewel Case 黑托盘；正背、书脊、内页、CD、册页封面 |
| Illinois | [AKR 014 气球封面](https://musicbrainz.org/release/777d51fe-b7c7-4874-9217-40abf09b4924) | Jewel Case 透明托盘；正背、书脊、内页、托盘下印刷、CD、折页封面 |

Lift 的 MusicBrainz `Digipak` 是宽泛标签；同版 [Discogs 1130206](https://www.discogs.com/release/1130206) 明确记载 gatefold sleeve，图集也无塑料托盘，因此使用 Gatefold。Loveless 不再沿用合成几何样本中的 Card Sleeve。Illinois 的 2D 与 3D 均采用所选气球封面。

映射声明位于 `tools/sample_reference_models.py`，四角为原图归一化坐标。册页正反面独立引用来源；发布、资源鉴权和备份校验均包含背面，未确认的背面不复制正面。模型生成/素材获取/结构校验仍使用 Album Engine；`tools/seed_reference_models.py` 只把这些固定声明和原图经 Store 事务接入样本库。CAA 优先，同版 Discogs 图先验证完整条码、目录号和 CD 介质。无已核对来源就停止发布，不用棋盘、封面复制或相似版本填补缺面。

公开版次原始图不裁切、不改像素，离线原件保留在 `bundle/assets/`，发布副本保留在 `instance/digital-twins/`；2D 封面超过大小限制时使用 CAA 自带的 500 px 缩略图，3D 仍引用原图。`manifest.json` 保留图集角色、来源 URL、实际尺寸与失败项；`sample-reference-model-report.json` 记录发行版、任务、映射指纹和发布资源 SHA-256。图片不跟踪、不随框架分发。准备阶段的 `reference-artwork/` 仅是导入暂存，发布成功后删除，避免第三份图片副本。

维护固定图集时可用 `seed_samples.py --fetch-covers --with-reference-models --reference-cache <已冻结的图集目录>`；日常预览使用上述统一入口。素材维护命令可复用缓存，目录下以 `lift-fists`、`loveless`、`illinois` 分组。相同来源和声明重复执行不增加任务。来源失败先于副本写入；每份已发布模型保留原资源。老的明确合成任务由新任务替换，只有其合成照片被清空，采购、金额、状态与其它副本保留。

`--with-reference-models` 与 `--with-models` 互斥。后者及 `--export-engine-fixtures` 仍是隔离的、明确虚构的离线几何测试，不能用作普通展示的视觉验收。参考模型使用标准尺寸，册页只映射已确认的可见面；不宣称还原了所有页数、背面或每条折线。
