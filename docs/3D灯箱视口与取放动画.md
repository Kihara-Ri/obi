# 3D 专辑灯箱：全视口与 CD 取放（2026-10-14）

## 视口及裁剪

此前 dialog 本身为全屏，但内部 `.gallery-focus-visual` 的最大宽度为 1000px，`.gallery-focus .album-model-scene` 的最大高度为 680px。引擎 `AlbumScene` 使用 stage 实际宽高作为 Canvas 尺寸、透视相机 aspect 和射线交互坐标，因此原先取出 CD 的大范围位移容易超出可见范围。

3D 模式现在为 `.gallery-focus-visual--model`、`.album-viewer`、`.album-model-scene` 分别设置 inset:0 和 100% 宽高；移除 dialog padding。标题与附件按钮绝对定位叠在舞台之上，不占用渲染空间。普通 2D 封面仍沿用原先居中容器以及共享封面缩放过渡。浏览器缩放或横竖屏改变时由引擎已有的 ResizeObserver 同步调整 Canvas 和相机纵横比。

## 点击空白关闭

WebGL 舞台现在覆盖整个视口。引擎原有的 `pick(x,y)` 射线检测负责区分包装/CD 实体和空白：空白点击调用 `onRequestClose`，宿主负责历史记录、退场动画和退出；拖动后的合成 click 由 `trailing` 抑制以避免误关。标题设置 `pointer-events:none`，不产生挡住点击的透明区域。导航、校准及附件按钮独立保持可交互。

## CD 取放运动

原先临界阻尼与三维几何位移的非线性映射造成观感不均：CD 向镜头移动主要在 `out` 进度尾段，收回时先经过这段大位移，看起来像突然抽走。

引擎 `advanceDiscMotion` 改为约 1.5 秒的缓入缓出 Hermite 轨迹。从静止状态 0→1 与 1→0 对每一时刻的进度严格互补，具有相同速度曲线。若中途反向，用当前 `out` 和 `velocity` 重建轨迹，保持初速度连续，先制动再返程；短剩余距离按平方根缩放时间。仅在运动结束时执行最终归位和多碟换碟，防止起始极小位移被判定为已到达。镜头空间 `discFramingRoom` 继续共享进度值。减少动态效果时仍瞬时跳到目标。
